# Testing, Security & Ops 필수 규칙

> 제목 옆 `PR #n`·`RECFIX-1` 같은 출처는 규칙이 생긴 리뷰를 가리킨다. `PR #n`은 **옛 저장소 번호**이며 이 저장소(`choise-hun/doloop`)의 PR 번호와 다르다.

## 1. 테스트 단언문(Assertion) 왜곡 절대 금지 (PR #8, #11, #13, #33)
- 비동기 인터페이스(Promise 반환 함수)가 동기로 throw하는 버그를 잡기 위해 assert.rejects에 async () =>를 씌우지 않는다:

    // 금지: 동기 예외를 Promise reject로 둔갑시킴
    await assert.rejects(async () => apiCall());

    // [필수 패턴]: 함수 호출 래퍼만 전달하여 동기 throw 발생 시 테스트가 실패하게 함
    await assert.rejects(() => apiCall());

- A || B 형태로 항상 참이 되는 단언 금지.
- 사전 차단(400/409) 테스트는 HTTP 상태 코드뿐 아니라 스토리지(fake.objects) 및 DB 행이 0건(무변경)임을 함께 단언한다.
- E2E 테스트에서 waitForTimeout 같은 임의 sleep 금지 -> page.waitForResponse 등 결정적 이벤트 대기만 사용한다.
- test/e2e/*.spec.js 파일 내부에서 헬퍼 함수를 module.exports로 내보내지 않는다 (별도 support/ 파일로 분리).

### 1.1 테스트 변경과 실패 증거

- 테스트 실패 원인은 구현·테스트·환경·데이터로 구분한다. 실패만으로 프로덕션 결함을 단정하거나 실제 출력에 기대값을 맞추지 않는다.
- 통과만을 위한 단언 완화, 케이스 삭제·주석 처리·skip, 항상 참인 단언, mock의 설정값만 그대로 확인하는 단언을 금지한다. 특정 테스트 입력만 통과시키는 하드코딩도 금지한다. 명세상 상수·fixture·검증 목적이 있는 mock은 허용한다.
- 승인된 요구사항 변경, 기존 테스트의 결함, 필요한 회귀 검증에 근거한 테스트 추가·수정은 허용한다. 변경한 테스트·기대 계약·기존 단언이 부적절한 이유(해당 시)·검증 결과를 결과 파일에 기록한다. 승인 밖 계약 변경은 사용자 결정 관문을 따른다.
- 중요한 결함 회귀는 수정 전 코드에서 해당 테스트의 의도한 실패(Red), 수정 후 통과(Green)를 확인한다. 기존 사용자 변경은 덮어쓰지 않고 격리된 사본에서 확인한다. 실행하지 못하면 이유와 미검증 범위를 남긴다.
- 실패 조건 설명, 정적 가드↔단언 대조, 실제 변이 검사는 다른 증거다. 실제 변이 검사는 대상 가드·변이 내용·실행 명령·의도한 단언 실패·복원 후 결과를 남긴 경우에만 수행했다고 보고한다. 주석이나 추론을 변이 검사 통과로 보고하지 않는다.
- 모든 테스트에 변이 검사를 강제하지 않는다. 중요 실패 모드에서 검증 강도가 부족할 때 적용하며 명세만 요청된 작업에서는 실행하지 않는다.
- `as any`, 무근거 캐스팅·non-null 단언, 빈 catch·임의 fallback으로 타입 오류나 실패를 숨기지 않는다. 명세상 복구·기본값은 해당 조건과 관찰 가능한 결과를 검증한다.
- 자가 점검 보고에는 확인 대상·실제 결과·미확인 범위를 적는다. 체크 표시나 자신감만으로 검증을 대신하지 않는다.

## 2. 보안 및 인프라 가드레일 (PR #9, #25, #27, #31)
- SSRF 방어: 외부 연동 다운로드 시 신뢰된 호스트 및 https:// 스킴만 허용하고 임의의 external.url은 즉시 건너뛴다.
- CSP & CORS: 운영 설정에 localhost, 127.0.0.1 포함 금지. API 출처 변경 시 config.js와 HTML meta connect-src를 동시 갱신한다.
- Cloud Run Jobs: containerOverrides 호출 시 이미지 기본 ENTRYPOINT를 덮어쓰는 args 대신 env만 전달한다.
- 상호 인증(OIDC): 서버 검증용 환경변수와 스케줄러 호출용 audience URL은 배포 스크립트 내 단일 변수로 일원화한다.
