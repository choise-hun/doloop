# 프론트엔드 디자인 규칙 (색·형태·글자)

화면에 실제로 적용하는 디자인 규칙이다. 값의 원본은 `frontend/src/styles/tokens.css`이고, 배치·간격 검사는 [정렬 규격](../../개발산출물/프론트_정렬규격.md)이 맡는다. 이 문서는 "어떤 토큰을 어디에 쓰는가"만 정한다.

> 루트 `DESIGN.md`는 사용자의 개인 취향 프로필(참고 자료)이며 git에 올리지 않는다. 다른 PC·다른 에이전트에는 없으므로 규칙의 근거로 인용하지 않는다. 이 문서·`tokens.css`와 내용이 다르면 이 문서와 `tokens.css`가 기준이다.
> 2026-11-18 개정(홈 UI 융합 4:6 + 쿨 라이트 + `▶ PLAYER` 확정, 전 페이지 일괄 적용): 시안은 [HOME_융합_시안.html](../../개발산출물/명세/HOME_융합_시안.html).

## 1. 색

- 색은 `tokens.css`의 변수로만 쓴다. 화면 CSS에 hex·`rgb()` 값을 직접 적지 않는다. 반투명이 필요하면 `color-mix(in oklab, var(--토큰) N%, transparent)` 또는 `tokens.css`에 명시한 파생 토큰을 쓴다(E2E `G5b` 오탐 방지).
- 순백(`#fff`, `#ffffff`)은 쓰지 않는다. 라이트 기본 표면은 따뜻함을 20% 낮춘 쿨 미네랄 뉴트럴을 쓴다: 바탕 `--bg`(`#ECEEF0`), 카드·패널 표면 `--surface` / `--paper` (`#F1F4F7`), 보조 표면 `--cream` (`#EDF0F3`), 한 단계 눌린 면 `--surface2` (`#DCE0E5`), 선 `--line` / `--surface3` (`#C7CCD3`), 프로스티드 면 `--panel-frosted`, 줄눈 `--seam-hairline`, 하이라이트 `--seam-highlight`, 릴리프 두께면 `--relief-bottom-mid`.
- 강조는 색을 더하지 않고 명도와 굵기로 만든다. 글의 위계는 `--ink` (`#1D1D1F`, 본문)와 `--muted` (`#61656C`, 보조), 글자 크기·굵기로 구분한다.
- `--surface2` 면 위의 글자는 `--ink`를 쓴다. `--muted`는 대비 부족으로 쓰지 않는다.
- **창 안의 색 (85:10:5 / H2):** 상단 메뉴·하단 탭 바·프레임·외곽 구조는 무채색(`--bg`, `--surface`, `--cream`, `--seam-hairline`)으로 유지하고, 유채색·조형 포인트 색(`--fill1`~`3`)은 **블록 좌측 스파인, 썸네일/표지, 지판·다이어그램, 화면당 1개의 대표 주 행동** 안에서만 쓴다.

| 용도 | 토큰 | 쓰는 곳 |
| --- | --- | --- |
| 대표 주 행동(화면당 1개) | `--fill1` (`#E64D01`) / `--accent` | 화면의 대표 주 CTA 필 버튼 1개(`--fill1` 배경 + 고대비 글자) 및 최우선 강조 |
| 선택 상태·먹색 구조 | `--accent` / `--accent-ink` | 선택된 컨트롤·강조 표식. 넓은 면의 무거운 검정 채움은 최소화한다(H3) |
| 스파인·섹션 조형 색 | `--fill1`, `--fill2` (`#7F93A8`), `--fill3` (`#8BA1A8`), `--section-spine` | 카드·섹션 좌측 `12px` 컬러 스파인 및 해당 섹션 내부 활성 항목(`이어서` 등) |
| 파랑(기존 화면 전용) | `--link`, `--root`, `--guide`, `--blue-vivid` | 본문 링크, 지판의 근음·가이드 음. 이미 쓰는 곳만 유지하고 새 화면·새 요소에는 쓰지 않는다 |
| 주황(포인트) | `--now*`, `--moved`, `--orange-*`, `--fill1` | 지금 칠 음, 바뀐 음, 스트릭·오늘 표시, 대표 주 버튼, `▶ PLAYER` 밑줄. 글자색으로 쓰지 않는다(라이트 대비 3.3~3.6) |
| 상태 | `--good`, `--bad` | 성공·오류 문구와 표시 |
| 선·줄눈 | `--line`, `--seam-hairline`, `--seam-highlight` | 카드·패널·입력의 `1px` 테두리와 4×4 파사드 격자 줄눈 |
| 덮는 면 | `--scrim` | 모달·서랍 뒤 배경. 다크에서도 어둡다 |
| 영상 바탕 | `--media-bg` | 영상 레터박스 |

- 가장 강한 채움(`--fill1` 필 또는 `--accent` 면 채움)은 한 화면에서 **동시에 보이는 대표 주 행동 하나**에만 쓴다(Q1). 목록의 각 항목마다 채움 버튼을 반복하지 않는다. (과거 홈 커뮤니티 배너 예외는 커뮤니티 비활성 기간 중 적용하지 않는다.)
- 다크 모드 값은 `tokens.css`의 `:root[data-theme="dark"]`와 `prefers-color-scheme` 블록 두 곳에 같은 값으로 둔다. 새 토큰을 추가하면 세 블록 모두에 넣는다.

### 알려진 예외

토큰 밖 색은 없다(DS-1에서 0으로 정리). `test/design_rules.test.js` DR-4가 `tokens.css` 밖의 hex·`rgb()`·`hsl()`을 모두 실패로 본다.

## 2. 형태

- 곡률은 **3가지 토큰**만 쓴다. `--radius-pill` (`9999px`), `--radius-block` (`3px`), `--radius-card` (`0px`). 원형 점(리벳·범례 등)만 `50%`를 쓴다. 그 밖의 임의 중간 곡률(`4~16px` 직접 수치 등)은 쓰지 않는다. (썸네일·표지에 책표지 곡률 `5px 9px 9px 5px`를 쓰려면 별도 `--radius-cover` 토큰을 정의해 사용한다.)
- **버튼·컨트롤 3단계 위계(필 최소화):**
  1. **대표 주 행동 (필 `--radius-pill`):** 한 화면에서 가장 중요한 핵심 행동 **1개**(예: 홈 URL 확정 후 `▶ 바로 연습`, 재생/저장 대표 CTA)만 `9999px` 필로 만든다.
  2. **사각형 컨트롤 (`--radius-block`, `3px`):** 한 줄 입력창(URL 입력 등), 범위 세그먼트(`합산 | 레퍼런스 | 분석`), 섹션 이동·보조 버튼(`코드 연습실`, `▶ 플레이어`, `노트 만들기`), 분류/목록 행 버튼. 외곽선은 `1px solid var(--seam-hairline)` 또는 `var(--line)`, 배경은 `--paper` / `--cream`, hover 시 `border-color: var(--ink)`로 맞춘다.
  3. **텍스트 버튼(글자 링크):** 카드 안의 이동·조작 행동(`전체 노트 →`, `이동 →`, `랜덤 ↻`, `연주하기 →`, `취향 통계 보기 →`, `기록 보기 →`, `이어서 연습 →`)은 배경·테두리 없는 굵은 글자 버튼으로 쓴다. `390`·`768` 폭에서는 터치 높이 `44px` 미달 경고가 나지 않도록 줄 패딩·간격을 확보한다.
- **태그·라벨:** 누를 수 없는 라벨(장르·레벨·상태 태그)은 필로 만들지 않고 직각/블록(`--radius-block` 또는 `0px`) `1px` 테두리 또는 `--muted` 텍스트로 쓴다.
- **카드·프레임·스파인 & 2겹 릴리프 (전 페이지 공통):**
  - 카드·패널·모달은 `--radius-block` (`3px`) + `border: 1px solid var(--seam-hairline)` + 2겹 릴리프 그림자(`--relief-bottom-mid`, `--shadow-ambient`)와 미세 파사드 줄눈(`--seam-hairline`) 위에 배치한다.
  - 기존 상단 `3px` 바(`border-top: 3px solid`)는 **좌측 `12px` 컬러 스파인(`--section-spine`, 상단 아치 슬릿 선택 적용)**으로 전환한다.
  - **내부 강조 일관성:** 섹션 내부의 활성 항목(예: `BETTER CHORDS`의 `'이어서'` 항목) 좌측 강조선·연한 배경 틴트 색은 반드시 해당 섹션 카드의 `--section-spine` 색과 일치시킨다.
- **전역 내비게이션 (`AppShell`):**
  - 상단 메뉴와 모바일 하단 탭 바 순서는 **`HOME` → `PLAYER` → `LEARN` → `TRAILS` → `CHORDS` → `NOTES`**로 고정한다(`PLAYER`를 `LEARN`보다 앞에 둔다).
  - **`PLAYER` 메뉴 강조(A안 확정):** 상단 내비게이션의 `PLAYER` 항목은 `▶` 아이콘 + `1px solid var(--ink-strong)` 사각 프레임(`--radius-block`) + 하단 `2px solid var(--fill1)` 밑줄로 강조한다. 모바일 하단 탭 바에서도 `▶ PLAYER`를 첫 기능 탭으로 배치한다.
  - `COMMUNITY`는 `communityEnabled()`가 꺼져 있는 동안 내비게이션·탭·홈에서 비노출한다.
  - 취향 코드 진행 범위 탭 순서는 **`합산` → `레퍼런스` → `분석`**(기본 선택 `합산`), 랜덤 버튼 문구는 **`랜덤`**(또는 `랜덤 ↻`) 글자 버튼으로 둔다.
- JSX 인라인 `style`로 곡률·색을 넣지 않는다. CSS 모듈 클래스로 제어한다.

## 3. 글자·컨트롤 크기

- 글꼴은 `--font-body` (본문), `--font-display` (큰 제목), `--font-mono` (코드·숫자·계기판 라벨) 세 가지다.
- 화면의 대표 버튼은 공통 클래스 `.pillBtn`(채움)을, 사각 보조 버튼은 `.ghostBtn` / `.sectionBtn`(`--radius-block`)을 쓴다: 대표 버튼 높이 48px, 글자 17px, 굵기 700.
- 목록·카드 안의 사각 보조 버튼은 높이 36~40px, 글자 13~14px로 쓰고, 그 카드의 제목보다 크거나 굵어 보이면 안 된다.
- **섹션 제목 (T1 Light):** 구역/섹션 큰 제목(`24px`)은 `font-weight: 300`(Light)으로 크기로 존재감을 내고 무게로 압박감을 뺀다. 본문 강조·라벨에만 `700`을 쓴다.
- **계기판 목소리 (T4, `DR-6` 12px 하한 유지):** 숫자·코드·기준일·영문 메타 라벨은 `DR-6` 최소 본문 기준인 **`12px`**을 유지하면서 `font-family: var(--font-mono)`, `font-weight: 500`, `letter-spacing: 0.08em`, `text-transform: uppercase`, `color: var(--muted)` 스타일을 적용해 한글 본문과 분리한다.
- 본문에 쓰는 글자는 12px 이상이다. 11px 이하는 지판·다이어그램 안의 표기처럼 공간이 정해진 `KNOWN_SMALL_TEXT` 허용 파일에만 쓴다.
- 글자 크기는 아래 단계 값만 쓴다. 단계 밖 값(예: `14.5px`·`20px`·`22px`)을 쓰지 않고, `font:` 축약으로 크기를 정하지 않는다. 글자 크기 토큰은 없고 `DR-6`이 검사한다.
- 11px 이하는 `test/design_rules.test.js`의 `DR-6` 허용 표(`KNOWN_SMALL_TEXT`)에 있는 파일에서만 쓴다. 본문용으로 표에 파일을 추가하거나 숫자를 올리지 않는다.

| 단계 | 값 | 쓰는 곳 |
| --- | --- | --- |
| 본문·라벨·계기판 | `12px` · `13px` · `14px` | 계기판 메타·배지·상태·보조 문구(12), 본문·메타(13), 기본 본문·작은 버튼(14) |
| 강조 본문·입력 | `15px` · `16px` · `17px` | 카드 제목·입력(16), 대표 버튼(17) |
| 제목 | `18px` · `24px` · `32px` | 패널 제목(18), 구역 Light 제목(24), 큰 숫자·프레임 제목(32) |
| 큰 제목 | `clamp(24px, 5vw, 38px)` · `clamp(36px, 7vw, 56px)` · `clamp(48px, 10vw, 96px)` | 화면 제목. 새 `clamp()` 값을 만들지 않는다 |
| 고정 칸 표기 | `6px` · `8px` · `9px` · `10px` · `11px` | 지판·건반·다이어그램·썸네일·요일 칸 안(허용 표의 파일만) |
- 포커스는 전역 `:focus-visible`(2px `--accent` 외곽선)을 그대로 쓰고 화면에서 지우지 않는다. 비활성은 `opacity: 0.4`다.
