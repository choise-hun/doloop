## 1. 목표 (CH-0 확정 요약)

- `CHORDS` 메뉴를 켜고 코드 진행 모음 한 페이지를 만든다: 입력(코드 진행 영상 / 직접 / 붙여넣기) + 목록(범위 **레퍼런스(기본) / 분석 / 합산**) + 취향 코드 진행(빈도 순위 + 랜덤)
- **분석** = 코드 진행 영상(CHORDS 입력 → 진행 전용 프롬프트 → 노트도 남김, 바로 수집) + 학습 영상 노트(노트 상세 "코드 진행 수집에 넣기" 켜고 끄기)
- **레퍼런스** = 좋아하는 실제 곡의 진행을 직접 입력. 입력 보완: 붙여넣기 파서, 로마숫자 자동 계산(키 추정 → 확인), 읽는 법 안내
- 수정은 웹에서. 노션 `코드 진행` DB(템플릿)로 **push만**, 노션 수정은 반영 안 됨 표기
- 홈 "취향 코드 진행 꺼내보기"를 새 데이터·범위 토글로 교체
- **연습실 연동(확정)**: 진행 → "연습실에서 직접 연주해볼까요?" 같은 버튼 → 연습실이 그 진행을 받아 연주·보이싱 탐구로 이어짐. 흐름은 `결과/CH-1a_프레임.md`(확정): 연습실 새 탭 "진행 연주", URL로 전달, 엔진에 퀄리티 추가(3화음 포함), 건반 진행은 기타로 연주 + 노트 링크
