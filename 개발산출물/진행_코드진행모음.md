# 진행: CHORDS — 코드 진행 모음 (수집 · 레퍼런스 · 취향 코드 진행)

- **최종 갱신:** 2026-11-04 (win) — CH-0 범위 확정 완료, 다음은 CH-1 설계
- **브랜치:** `feat/chord-collection` (base `main`)
- **근거:** 루트 `코드진행_기능_기획_메모.md`(= `docs/ULevelP 코드 진행 기능 기획 메모.md`), 노션 템플릿 "🎼 진행 모음 (템플릿)", **확정 범위는 `결과/CH-0_범위확정.md`가 우선**
- **범위:** React(`frontend/src`) + Kotlin 서버. 레거시 `public/*` 제외. 1차는 개인용(공개 레퍼런스는 2차)
- **배포:** 이 작업 1차가 main에 들어간 뒤 한꺼번에(인수인계 메모 §2). 그때 Flyway V2·V3가 운영 DB에 처음 같이 적용된다

## 1. 목표 (CH-0 확정 요약)

- `CHORDS` 메뉴를 켜고 코드 진행 모음 한 페이지를 만든다: 입력(코드 진행 영상 / 직접 / 붙여넣기) + 목록(범위 **레퍼런스(기본) / 분석 / 합산**) + 취향 코드 진행(빈도 순위 + 랜덤)
- **분석** = 코드 진행 영상(CHORDS 입력 → 진행 전용 프롬프트 → 노트도 남김, 바로 수집) + 학습 영상 노트(노트 상세 "코드 진행 수집에 넣기" 켜고 끄기)
- **레퍼런스** = 좋아하는 실제 곡의 진행을 직접 입력. 입력 보완: 붙여넣기 파서, 로마숫자 자동 계산(키 추정 → 확인), 읽는 법 안내
- 수정은 웹에서. 노션 `코드 진행` DB(템플릿)로 **push만**, 노션 수정은 반영 안 됨 표기
- 홈 "취향 코드 진행 꺼내보기"를 새 데이터·범위 토글로 교체
