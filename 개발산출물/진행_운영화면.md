### 질문 아님 — AI가 해당 step에서 정한다 (기록만)

- **사유(`reason`):** 쓰기 폼마다 사유 칸, 작업 이름으로 기본값을 채워 둔다(예: "크리에이터 지정", "이달의 곡 2026-12 곡 교체") — 고칠 수 있음, 비면 버튼 비활성
- **곡 입력:** 유튜브 주소나 영상 ID를 붙여 넣으면 `videoIdFrom`으로 ID를 뽑는다. 구간은 `분:초` 또는 초, 배속 0.25~2(기본 1), 곡 설명 ko ≤ 300자. 곡 제목·채널명은 입력하지 않는다 — 저장 뒤 서버가 주는 YouTube 값을 보이고, 저장 전에는 썸네일 + ID
- **개수 상한:** 이달의 곡 5, 큐레이션 50 — 화면에서도 막고, 서버 400 `detail.max`도 그대로 보인다
- **이달의 곡 `month`:** 만들 때만 고른다(F6 — 못 바꿈, 지우고 다시 만든다). 기본값 = KST 다음 달(미리 만들어 공개해 둬도 그 달에만 보인다 — E4)
- **삭제:** 확인 한 번(`confirm`) + 사유
- **403 처리:** `/me`가 owner인데 `/admin`이 403이면(역할이 바뀐 경우) 섹션 안에 "owner 권한이 없어요" 한 줄만 보이고 폼을 숨긴다
- **비 owner:** 섹션을 렌더하지 않고 `/api/v1/admin/*` 요청도 보내지 않는다(e2e로 요청 0건 확인)
