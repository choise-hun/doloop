# DS-0 결과 — 홈 디자인·로고 결정

- 날짜: 2026-11-14 / Mac / Claude(시니어) + 사용자 결정
- 방법: [시안 페이지](../명세/DS_시안.html)에서 항목별로 고른 뒤 사용자가 최종 확정. 제품 코드 변경 없음.
- 주의: 시안 페이지에는 파랑·네이비 선택지가 남아 있지만 **최종 결정에서 폐기**했다. 이 문서가 기준이다.

## 1. 확정한 결정

| 항목 | 결정 |
| --- | --- |
| 유채색 | **주황 하나만** 쓴다. 값은 `#E64D01`(다크 `#FF6B2B`). 네이비·파랑을 새로 쓰지 않는다 |
| 글자·제목·탭·이동 링크(→) | 모두 기존 잉크 `--ink`(`#1D1D1F`). 새 토큰(`--head`)을 만들지 않는다 |
| 주 행동·선택 세그먼트 | 기존 `--accent` 채움(변경 없음) |
| 프레임 | 얇은 상단 바 3px만. 머리 틴트 없음. BETTER·WEEKLY 카드 = 주황, VAULT·RECENT 카드 = 잉크 |
| CHORDS 목록 | 번호는 잉크. "이어서" 항목은 왼쪽 3px 주황 선 |
| 커뮤니티 배너 | 잉크 면 채움 + `--accent-ink` 글자, 이동 링크는 밑줄 텍스트 |
| 스트릭 | 완료 칸 = 잉크 채움(현행), 오늘 칸 = 주황 테두리 + 주황 틴트, 작심삼일 점 = 주황 |
| 최근 곡 구간 배지 | 직각, 주황 테두리 + 주황 틴트 |
| 보조 글자 `--muted` | 현행 유지 |
| 헤더 | 1px `--line` 구분선, BETA 배지 현행(테두리) |
| 카드 제목 문구 | `WEEKLY STREAK` → `WEEKLY`, `가장 최근 연습했던 곡` → `RECENT` |
| 서비스 이름 | ULeveLP → **RE:DO** |
| 로고 | 형태 "직각 + 원"(R·E는 직각 획, D는 반원, O는 원, 콜론은 정사각형 두 개), 콜론은 상하 대칭(E의 두 틈 높이), 색은 잉크 단색. 가로형과 세로 2줄 조합(`RE:` / `DO`)을 함께 쓴다 |

로고 도형의 좌표 원본은 시안 페이지 스크립트의 `G`(R·E·Dround·Oround)와 `row()`의 콜론 위치(`center`: y 14·62, 한 변 24, 글자 높이 100 기준)다. BR-1에서 이 좌표로 SVG 파일을 만든다.

## 2. 규칙·토큰에서 바뀌는 것 (DS-1 입력)

- `tokens.css`: `--orange-terra`·`--now-ring`·`--moved`가 쓰는 주황을 `#E64D01`로(다크 `#FF6B2B`). `--now` 틴트 값은 DS-1에서 대비를 보고 정한다.
- `docs/rules/frontend-design.md` §2: "두꺼운 테두리(2px 이상) 금지"에 **프레임 상단 바 3px** 예외 추가.
- `docs/rules/frontend-design.md` §1: "가장 어두운 채움은 주 행동 하나와 선택 상태에만"에 **홈 커뮤니티 배너 면 채움** 예외 추가. "화면 하나에 유채색 한 가지"는 그대로 지켜진다.
- 대비: `#E64D01`/`--bg`는 약 3.4라 글자색으로 쓰지 않는다(표시·테두리 전용, 현행 규칙과 같음).
- RG-1 후속(계획 §4): ① 토큰 밖 색 25곳 교체와 허용 개수 내리기는 DS-1에 포함, ② `--muted`/`--surface2` 4.09·다크 `--root-ink`/`--root` 3.72는 DS-1 명세에서 처리안 제시, ③ 글자 크기 20종 정리는 DS-3.

## 3. 남은 확인 (DS-1 명세 전에 사용자에게 묻는다)

- **기존 파랑 토큰의 범위**: "파랑 폐기"가 홈·새 디자인에만 해당하는지, 이미 쓰는 `--link`(본문 링크)·`--root`(지판 근음 점)·`--guide`까지 잉크/회색으로 바꾸는지. 지판은 근음·지금 칠 음·나머지 음을 색으로 구분하므로 바꾸면 chords·player 화면 전체에 영향이 있다.
- 서비스 이름의 한글 표기 필요 여부, 도메인 변경 여부(BR 범위).

## 4. 검증

- 시안 페이지: 헤드리스 Chromium으로 라이트 1120폭·다크 390폭·로고 3형태 스크린샷 확인, 콘솔 오류 0건.
- 미실행: 제품 화면 적용, 레이아웃 spec, 4개 폭 스크린샷(DS-2 범위).
