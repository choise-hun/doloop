## 1. 구현 및 자체 검토

- 앱 전용 API Origin/config/CSP connect-src 주입. HTTPS Origin 입력 검증을 출력 폴더 삭제 전에 수행. 웹 config와 원본 CSP의 같은 출처 API 유지.
- JSON·keepalive·ZIP·take 다운로드 공통 URL, locale 헤더, uid/generation 가드. `Headers` 객체의 명시 언어 보존, token 대기·본문 소비·늦은 네트워크 실패의 이전 사용자 응답 폐기. keepalive의 Promise 계약 유지.
- 모바일 Origin은 ALLOWED_ORIGINS의 두 등록 문자열만 정확히 일치 허용. 기존 웹/확장과 JWT 검증·403 후 라우트 중단 유지. Accept-Language와 Content-Disposition 노출.
- App 8.1.2·Browser 8.0.5를 exact 고정. Google PKCE code/flowId 교환, warm/cold 복귀, 취소 표식·SDK 이벤트 격리·로그아웃/새 로그인 직렬화. SDK가 먼저 저장한 이전 세션도 정리 전 노출하지 않음.
- cold 세션 복원 대기 중 로그아웃의 세대 검사와 취소 표식 보존, SDK 로그아웃 통신 실패 후 재시도 복구 보강. 세션/프로필은 검증된 현재 attempt만 반영.
- iOS scheme·Android intent-filter 및 sync 생성물, 공통 상태 표시·ko/en/ja 문구·pending 버튼 비활성화. native 메뉴 로그인 취소는 현재 페이지에서 상태를 알리며 웹 fallback 동선은 보존.
- DB·기존 API 경로/DTO/상태 코드 변경 없음. Apple/Drive 모바일 인증·범용 딥링크·버튼 배치 개선은 범위 밖. M1A-2 A1~A6 검수 재실행 안 함.

### 2.1 중요 가드의 Red/Green

1. 임시 사본에서 auth.ts의 native SDK 이벤트 격리 가드만 제거 → N3 logout 테스트가 이전 A 사용자 통지를 검출해 `true !== false` 실패. 원본 무변경, 정상 소스 N3 통과. `/tmp/m1a3-mutation-red.log`.
2. 별도 임시 사본에서 nativeAuth.ts cold 복원 `generation/pending/cancelled` 검사만 제거 → 취소 표식/이전 사용자 통지 단언 실패. 원본 무변경, 정상 소스 N3 통과. `/tmp/m1a3-cold-mutation-red.log`.
3. 테스트 fake의 반환값만 보지 않고 SDK 저장과 이벤트 부수 효과, local signOut 완료·취소 표식 삭제 순서를 단언한다. A→B→A·같은 uid 재로그인·프로필 PATCH 큐의 기존 회귀를 유지했다.

- Supabase Redirect URLs의 `ulevelp://auth/callback`은 사용자 “등록 완료” 응답으로 확인. 대시보드 직접 조회나 실제 OAuth 성공으로 간주하지 않는다.
- iPad mini(A17 Pro): 최종 서명 앱 설치·실행 성공. 실제 Google 로그인 후 계정·곡 표시, 앱 완전 종료 후 세션 유지, 로그아웃·로그인 취소·재시도는 사용자 “세 항목 모두 정상” 응답으로 통과. iPhone17은 설치45초 timeout 후 순차 재시도로 최종 앱 설치·실행 성공. 같은 로그인/재시작 유지/로그아웃·취소·재시도는 사용자 “모두 정상” 응답으로 통과. Android 태블릿 TB371FC(HA1V3W22)는 최종 APK 설치·실행 성공, 사용자 “태블릿 확인 완료(전부 정상 동작)” 응답으로 Google 로그인·계정/곡 표시·재시작 세션 유지·로그아웃/취소/재시도 통과. ## 5. Git·재개

사용자 변경이 없던 main에서 시작해 기존 명세 문서 4개를 보존하고 작업 브랜치를 만들었다. 최종 변경은32개 파일(기존24·신규8), 모두 UTF-8 BOM 없음/LF·로컬 링크154개 및 git diff --check 통과. 배포 소스 지문은 마지막 파일 검사에서도 일치했다. Git 게시 승인을 추정하지 않았으므로 commit/push/PR 없음. 작업 중 생성한 Xcode Package.resolved는 `/tmp/m1a3-build-generated/`로 옮겨 소스 diff에서 제외했다. 현재 코드와 운영 차이·미검증 재개는 진행 §5를 따른다.
