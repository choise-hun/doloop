## 4. 명세와 달라진 점 및 겪은 문제

### 4.1 명세와 달라진 점
- **없음.** 명세서 1~8절에 기재된 파일 경로, 컴포넌트 시그니처, DOM ID, 비동기 가드, 1회 호출 제약, CSS 규격(순백 0건, 중간 곡률 0건)을 100% 일치하여 구현함.

### 4.2 겪은 문제 및 해결
1. **`test/r1_settings_notes.test.js` VM 실행 시 `export interface` 구문 에러:**
   - *문제:* Node.js VM 로더가 TypeScript의 `export interface` 구문을 인식하지 못해 `SyntaxError: Unexpected token 'export'` 발생.
   - *해결:* VM 로더의 정규식에 `replace(/export\s+interface\s+[A-Za-z0-9_]+\s*\{[\s\S]*?\n\}/g, '')`를 추가하여 런타임 이전 interface 선언을 제거하도록 처리함.
2. **`SanitizedSvg.tsx` Omit 타입 선언 문자열 정규식 검출:**
   - *문제:* `SanitizedSvg.tsx` 내 `Omit<React.SVGProps<SVGSVGElement>, 'dangerouslySetInnerHTML'>` 선언이 단순 `\bdangerouslySetInnerHTML\b` 정규식에 매칭되어 단언 실패.
   - *해결:* 실제 JSX 속성 할당인 `/\bdangerouslySetInnerHTML\s*=/`을 검사하도록 보정하여 안전하게 통과함.
3. **`node 개발산출물/자료/csp_check.js` 대조군 실패:**
   - *문제:* 로컬 웹 서버(`node server.js`)가 백그라운드에 떠 있지 않은 상태에서 실행하여 Chrome이 에러 페이지를 띄움에 따라 CSP 메타 태그가 로드되지 않아 대조군 위반 검출 실패.
   - *해결:* `node server.js`를 백그라운드로 기동한 후 `csp_check.js`를 실행하여 13개 화면 모두 통과(실패 0개)를 확인한 후 서버를 안전하게 종료함.
