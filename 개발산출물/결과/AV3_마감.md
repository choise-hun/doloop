- 대상: 시작 HEAD `4a6df1c`의 앱 코드 + AV-F3 작업본. 원격 main `cb4565c`와의 제품 차이는 auth/설정 호출자 2개 파일이다. 게시 커밋·PR·CI는 [마감 실행 기록](../진행_AV3_마감게시.md)에 기록한다.

## 3. 웹 확장 관문

- **개발 착수 관문**: 기존 M1/M2 로컬 사용 여정과 재현 결함 해소를 충족했다. 마감 PR CI 성공·사용자 머지 후 CH-A의 명세/개발을 다음 후보로 선택할 수 있다.
- **확장 완료·운영 인수 관문**: 위 운영/출시 전 항목은 그대로 남는다. CH-A 자체 수용 기준·레이아웃/실제 재생 보존 회귀도 별도로 충족해야 한다. 로컬 통과 또는 후속 화면 완성으로 운영·결제·외부 서비스/모바일 미검증을 덮지 않는다.
- 새 결함·변경·필수 증거 부족이 생긴 항목만 재검증한다. 기존 통과한 AV 전체, 실계정 로그인, 외부 유료 분석을 일괄 반복하지 않는다.

## 4. 이번 실행과 미실행

실행: Git/원격/PR 확인, 실제 diff·명세·단언·현재 해시/원시 결과·기존 로그 대조, 문서 판정/분류/인수인계 정리, 게시 대상 비밀값/인증자료 제외·링크/인코딩·diff 검사, PR CI 확인(최종 수치는 실행 기록).

미실행: 실계정 재로그인/전체 여정 재생성/O 재검수/추가 분석/운영 쓰기·배포/머지/CH-A 구현. 현재 근거와 수정 영향 범위가 맞으므로 마감 전에 동일 검수를 새로 실행하지 않는다.
