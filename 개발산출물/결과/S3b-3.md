## 2. 명세와 달라진 점 (시니어 구현 §13 기준)

1. **A3 단언 변경(서버):** 동의가 전혀 없는 사용자의 녹음 첨부 게시가 이제 `scope:"card"`로 거절된다(D12의 필연적 결과 — 카드 동의가 먼저 없고, 동의 1회가 카드·녹음을 함께 허용). A3는 `user(consent=false)`로 바꾸고 `card`를 단언하며, 녹음 동의 철회 뒤 `scope:"recording"` 단언을 추가해 녹음 분기 검증을 유지했다.
2. `ShareConsentStep`에 `nameForm` 전용 선택 props `checked`·`onCheckedChange`를 추가했다(§4.1 기본 시그니처 유지).
3. 세션 카드 맞춤 그룹 이름은 표면 구분을 유지해 `sessionHead-{surface}-{id}:center-y`로 두고, 공유 상태 배지 줄(숨김 사유 등)은 남긴 채 행동 버튼만 아이콘 메뉴로 옮겼다.
4. D15에 따라 업로드·게시 중에도 닫기를 허용하며, 게시 요청이 이미 나간 뒤 닫을 때 `invalidate`로 서버 상태를 다시 읽는다.
5. 미사용 문구 키 삭제(`episode.share.consent`, `episode.titleWithVideo`, `episode.share.unavailablePreview`, `episode.previewTitleLabel`). 공유 창 버튼은 공통 `.pillBtn`/`.ghostBtn`(frontend-design §3), 오류 상자는 `--bad` `color-mix`로 바꿔 `design_rules` 허용 개수를 5→2로 줄였다(`frontend-design.md` 표 갱신).
6. 기존 테스트 변경: `CUI-07`·`CUI-09`·`SR-02`·`SR-04`·`SR-06`·`SR-07`·`SR-09`·`SR-16`·`profile.spec.js` PF3 및 `cm_ui.test.js` 제목 규칙을 S3b-3 계약에 맞게 갱신.
7. 순서 편차: 시니어 표적 E2E(`U4`·`U15`)와 layout spec은 구현 뒤에 작성하고 변이 검사 2건으로 Red를 확인했다.
