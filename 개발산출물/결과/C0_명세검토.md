## 2. 이번 묶음에서 새로 정한 메뉴얼 항목 (기본안 확정)

### 2.1 `K3-1` — 노션 호환 ZIP 내보내기/가져오기 (`Export & Import`)
- **`StorageClient.download(key: String): ByteArray` 추가:**
  - `SupabaseStorageClient`: `GET $supabaseUrl/storage/v1/object/$bucket/$key` (`Authorization: Bearer $secretKey`, `apikey: $secretKey`) 호출, `200..299`이면 바이트 배열 반환, 실패 시 `StorageException`.
- **`GET /api/v1/export/zip?includeAudio=true`:**
  - 쿼리 파라미터 `includeAudio`: 생략·`"true"`이면 `true`, `"false"`이면 `false`, 그 외 값은 `400 INVALID_INPUT`.
  - 응답 헤더: `Content-Type: application/zip`, `Content-Disposition: attachment; filename="ULeveLP-export-${todayUtc}.zip"`, `Cache-Control: no-store`.
  - ZIP 엔트리 구성:
    1. `읽어주세요.txt`: 템플릿 복제 및 CSV 병합 안내문(UTF-8).
    2. `연습 곡.csv`: UTF-8 BOM(`\uFEFF`) + 헤더 `곡명,아티스트,상태,유튜브 링크,이어서 연습,마지막 위치(초),구간 시작(초),구간 끝(초),속도,마지막 연습일,메모` (11열).
    3. `연습 기록.csv`: UTF-8 BOM(`\uFEFF`) + 헤더 `기록,곡,날짜,연습 시간(분),반복 횟수,속도,구간,메모,녹음` (9열). `연습 시간(분)`은 `round(seconds / 60.0, 2)`, `구간`은 `SessionService.formatSegment(a, b)`, `녹음`은 해당 세션의 녹음 ZIP 상대 경로(`녹음/{date}_{HHmmss}_{safeTitle}_{takeId8}.{ext}`)를 `, `로 연결.
    4. `학습 영상 노트.csv`: UTF-8 BOM(`\uFEFF`) + 헤더 `제목,URL,태그,채널,요약,키워드,난이도,메모` (8열).
    5. `학습 영상 노트/{safeTitle}_{noteId8}.md`: 노트별 마크다운 본문.
    6. `녹음/{date}_{HHmmss}_{safeTitle}_{takeId8}.{ext}`: `includeAudio == true`이고 `storage == "supabase"`이며 `storageClient != null`일 때 바이트 수록(개별 파일 다운로드 실패 시 `runCatching`으로 건너뛰어 전체 ZIP 생성은 성공 유지).
- **`POST /api/v1/import/notion/preview` (`multipart/form-data`, 파트 `file`):**
  - 크기 제한: ZIP 파일 최대 100MB(`104_857_600L`, 초과 시 `413 ZIP_TOO_LARGE`), 압축 해제 총량 최대 200MB(`209_715_200L`, Zip Bomb 방어, 초과 시 `400 INVALID_INPUT`), 최대 엔트리 1,000개.
  - 노션 내보내기 구조(파일명 뒤 32자리 해시 접미어, 1단계 중첩 `.zip`, 하위 폴더 오디오 파일)와 우리 서비스 내보내기 ZIP 구조를 모두 지원.
  - 파싱 결과를 인메모리 `ImportPreviewStore`(TTL 15분, 사용자당 최대 3개 보관)에 저장하고 DB는 변경하지 않음(`FR-NX-4`).
  - 응답(`200 OK`, `ImportPreviewResponse`):
    `{ "ok": true, "previewToken": "...", "newSongs": Int, "updatedSongs": Int, "sessions": Int, "takes": Int, "songsSample": List<ImportSongSampleDto>, "errors": List<ImportRowErrorDto> }`.
- **`POST /api/v1/import/notion/confirm`:**
  - 요청 본문: `{ "previewToken": "<uuid>" }`. 없거나 만료됐거나 타 사용자 토큰이면 `404 NOT_FOUND`.
  - 단일 DB 트랜잭션(녹음 파일 스토리지 업로드는 트랜잭션 밖 선행, 실패 시 보상 정리)으로 곡(`(user_id, video_id)` Upsert), 세션(`(user_id, song_id, date)` 덮어쓰기 Upsert — 멱등성 보장), 녹음(쿼터 200MB 이내 업로드 및 동일 세션·녹음 시각·크기 중복 건너뜀) 반영.
  - 응답(`200 OK`, `ImportConfirmResponse`):
    `{ "ok": true, "createdSongs": Int, "updatedSongs": Int, "upsertedSessions": Int, "importedTakes": Int, "skippedTakesByQuota": Int }`.

### 2.2 `K4-1` — 외부 연동 키 관리 API (`/api/v1/integrations`) 및 `ulp:keys`
- **`CryptoService.fromEnvOrNull(env)` 추가:**
  - `APP_MASTER_KEY`가 없거나 비어 있으면 `null`을 반환(경고 로그 출력), 형식이 잘못되었으면 기동 시 예외 발생.
  - `cryptoService == null`일 때 암호화/복호화가 필요한 요청(`PUT /integrations/*`, `POST /integrations/*/check`, 노션 동기화)은 `503 CRYPTO_UNAVAILABLE` 반환.
- **API 5종 (`IntegrationRoutes`, `IntegrationService`):**
  - `GET /api/v1/integrations?appId=ulevelp` → `200 OK` `{ "integrations": List<IntegrationDto> }` (`provider`, `hint`, `config`, `updatedAt` 4필드).
  - `PUT /api/v1/integrations/notion` → 본문 `{ "appId"?: "ulevelp", "token"?: "ntn_...", "songsDb": "...", "sessionsDb": "...", "notesDb"?: "..." }` → `200 OK` `IntegrationDto`. 최초 등록 시 `token` 필수, 수정 시 `token`이 `null` 또는 빈 문자열이면 기존 암호문 유지하고 `config`만 갱신(`FR-KEY-2`). DB ID는 하이픈 제거 소문자 32자리로 정규화.
  - `PUT /api/v1/integrations/gemini` → 본문 `{ "appId"?: "ulevelp", "apiKey"?: "AIza...", "model"?: "gemini-flash-latest" }` → `200 OK` `IntegrationDto`.
  - `POST /api/v1/integrations/{provider}/check?appId=ulevelp` → 키 미등록 시 `412 NO_KEY`. 외부 API 401/403 시 `400 PROVIDER_KEY_INVALID` (`source = "notion"` 또는 `"gemini"` — 클라이언트가 `ulp:keys` 즉시 무효화), 노션 404 시 `404 NOTION_OBJECT_NOT_FOUND`, 필수 속성 누락 시 `400 NOTION_SCHEMA_MISMATCH` (누락된 속성명 전체 나열), Gemini 모델 404 시 `404 GEMINI_MODEL_NOT_FOUND`. 성공 시 `200 OK` (`NotionCheckResponse` 또는 `GeminiCheckResponse`).
  - `DELETE /api/v1/integrations/{provider}?appId=ulevelp` → `integrations` 행 삭제 + `provider == "notion" && appId == "ulevelp"`이면 같은 트랜잭션에서 `notion_sync.enabled = false, lease_until = null, lease_owner = null`로 변경(`FR-KEY-4`) → `200 OK` `{ "ok": true }`.

### 2.3 `K4-2` — 노션 실시간 동기화 — 보내기 (`NotionPushWorker` & Cron)
- **`NotionClient` (`src/main/kotlin/ulevelp/notion/NotionClient.kt`):**
  - 노션 API(`2022-06-28`) 호출 및 `429 Retry-After` 지수 백오프 재시도(최대 3회), `Code.gs` `upload()`와 동일한 파일 업로드(20MB 이하 단일 파트, 20MB 초과 시 10MB 멀티파트 `/v1/file_uploads` → `/send` → `/complete`) 구현.
- **`NotionPushWorker` (`src/main/kotlin/ulevelp/notion/NotionPushWorker.kt`):**
  - `notion_sync` lease 획득(`lease_until = now() + 5분`) → `sync_outbox`(`done_at IS NULL AND attempts < 5`, 엔티티 의존 순서 `song` → `session` → `take` → `note`, `id ASC`, 최대 20건) 순차 처리 → 항목마다 lease 연장 → 완료 시 `done_at = now()`, 실패 시 `attempts + 1` 및 `last_error` 기록 → lease 해제 및 `last_push_at = now()` 갱신.
  - `song`·`session`·`take` 요청 본문은 `apps-script/Code.gs` 및 `docs/04-db-design.md` 4.1·4.2절과 100% 일치. `delete`는 노션 페이지/블록을 `archived: true`로 전환하고 `notion_links` 행을 삭제.
- **엔드포인트:**
  - `POST /api/v1/notion/sync/push`: 로그인 사용자의 본인 Outbox 즉시 실행 → `200 OK` `{ "ok": true, "processed": Int, "failed": Int }`.
  - `POST /internal/cron/notion-push`: `CronOidcVerifier`(Google JWKS RS256 + `CRON_AUDIENCE` + `CRON_SA_EMAIL`) 검증 통과 후 ① 대기열 있는 사용자 Push ② `storage_trash` 미삭제 파일(`attempts < 5`) `purge` ③ 70분 초과 `running` 상태 `analysis_jobs` 타임아웃 정리 → `200 OK` `{ "ok": true, "pushedUsers": Int, "processedOutbox": Int, "purgedTrash": Int, "timedOutJobs": Int }`.

### 2.4 `K4-3` — 노션 실시간 동기화 — 가져오기 (`NotionPullService` & `full` 모드) + 레거시 제거
- **엔드포인트 4종 (`NotionSyncService` / `NotionSyncRoutes`):**
  - `GET /api/v1/notion/sync/status` → `200 OK` `{ "enabled": Boolean, "pending": Int, "failed": Int, "lastPushAt": String?, "lastPullAt": String?, "lastError": String? }`.
  - `POST /api/v1/notion/sync/enable` → 드라이브 저장소 사용 중이면 `409 NOTION_SYNC_CONFLICT`(`FR-SYNC-5`), 노션 키 미등록 시 `412 NO_KEY`. 노션 `songsDb`·`sessionsDb` 전체 조회 및 오디오 파일 스토리지 이관(200MB 쿼터 초과분은 `skippedTakesByQuota`로 집계, 2회 실행 시 중복 0건 멱등성 보장), 로컬 미연결 곡·세션·녹음 Outbox 적재 후 `enabled = true` 설정 → `200 OK` `{ "ok": true, "importedSongs": Int, "importedSessions": Int, "importedTakes": Int, "skippedTakesByQuota": Int }`.
  - `POST /api/v1/notion/sync/disable` → `enabled = false` 전환 → `200 OK` `{ "ok": true }`.
  - `POST /api/v1/notion/sync/pull` → 노션 키 미등록 시 `412 NO_KEY`, 연동 꺼짐 시 `400 INVALID_INPUT`, `last_pull_at`으로부터 5분(300초) 미경과 시 `429 RATE_LIMITED`(`retryAfter` 초 반환). `last_edited_time > last_pull_at`인 곡·세션을 조회해 DB에 반영하되 **`sync_outbox`에는 절대 적재하지 않음(무한 루프 방지)** → `200 OK` `{ "ok": true, "updatedSongs": Int, "updatedSessions": Int, "lastPullAt": String }`.
- **레거시 제거 (`K4-3`):**
  - `apps-script/Code.gs`, `apps-script/README.md` 삭제.

  - `test/security.test.js`의 `STORAGE_LEGACY`에서 `pp-api`·`pp-key` 제거, `CSP` `connect-src`에서 `https://script.google.com https://script.googleusercontent.com` 제거 및 `public/*.html` 7개 파일의 CSP `<meta>` 일괄 갱신.
