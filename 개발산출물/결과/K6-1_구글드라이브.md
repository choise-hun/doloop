## 3. KZ-1이 쓸 값

### 3.1 `window.ULDrive` 공개 메서드 목록

- `requestToken(opts)`: Google Identity Services (`drive.file`) 인메모리 액세스 토큰 획득 (`Promise<string>`).
- `ensureFolder(preferredId)`: `ULeveLP 녹음` 폴더 존재 확인 및 자동 생성 후 folderId 반환 (`Promise<string>`).
- `uploadBlob(blob, name, mime, folderId)`: 5MB 이하 multipart 단일 요청 / 5MB 초과 Resumable Upload 세션 분기 업로드 후 driveFileId 반환 (`Promise<string>`).
- `uploadTake(meta, blob)`: folder 확보 -> blob 업로드 -> `ULData.takes.registerDrive` 호출 (`Promise<TakeDto>`).
- `fetchMediaObjectUrl(fileId)`: Google Drive `alt=media` 다운로드 후 `URL.createObjectURL` Blob URL 반환 (`Promise<string>`).
- `enableDriveStorage()`: Drive 저장소 활성화 및 `PATCH /api/v1/me` 호출 (`Promise<MeResponseDto>`).
- `disableDriveStorage()`: 기본 저장소로 복귀 및 `PATCH /api/v1/me` 호출 (`Promise<MeResponseDto>`).
- `migrateAllToDrive(onProgress)`: 기본 저장소에 남아 있는 녹음 다운로드 -> Drive 업로드 -> `migrateToDrive` 일괄 이전 (`Promise<{ migrated, skipped }>`).
- `clearToken()`: 인메모리 OAuth 토큰 및 만료 시각 즉시 초기화.

## 4. 명세와 달라진 점 및 겪은 문제

- **명세와 달라진 점:** 없음.
- **겪은 문제 및 해결:**
  - `TakeApiTest`의 `T23`에서 `SongDetailResponse`의 JSON 구조상 `takes`는 세션 하위가 아닌 루트 레벨 배열(`songJson["takes"]`)에 속함. 이를 반영하여 `takes[0].sessionId == sessions[0].id`로 올바르게 단언함.
  - `test/data.test.js`의 `D34` 작성 시, 가짜 fetch 응답 핸들러에서 `Location` 주소(`https://www.googleapis.com/upload/drive/v3/files?uploadType=resumable&upload_id=sess_abc`)에 `uploadType=resumable`이 포함되어 두 번째 PUT 요청 시 첫 번째 세션 초기화 분기로 잘못 진입함. `url === resumeUrl` 분기를 우선 평가하도록 수정하여 해결함.
