## 2. API (실제 동작)

| 경로 | 입력 → 응답 |
| --- | --- |
| `GET /api/v1/songs/import-playlist/preview?url=` | → `{playlistId, title, itemCount, remainingSongSlots, remainingCategorySlots}` (남은 칸 null = 제한 없음 — 지금 티어는 모두 제한 있음). YouTube는 `playlists` 1회만 |
| `POST /api/v1/songs/import-playlist` | `{url, categoryId}` 또는 `{url, newCategory:true, categoryName?}` → 200 `{categoryId, categoryCreated, playlistTitle, imported, alreadyInLibrary, skippedLimit, skippedUnavailable}` |

- 순서: 입력 검사 → YouTube 호출(트랜잭션 밖, 앞 **500개**까지) → 트랜잭션(`profiles` `FOR UPDATE`) 안에서 분류 확인/생성 → 재생목록 순서대로 처리
- 항목 처리: 비공개·삭제 → `skippedUnavailable` / 이미 있는 곡 → 분류에만 넣고 `alreadyInLibrary`(칸 안 씀, 제목 등 그대로) / 남은 칸 있으면 새 곡(제목 = 영상 제목, 아티스트 = `videoOwnerChannelTitle`, 노션 outbox 등록) `imported` / 칸 없음 → `skippedLimit`
- 이 step에서 정한 것:
  - 재생목록 안 **같은 영상이 두 번** 나오면 처음 것만 처리하고 두 번째는 어느 수에도 안 센다(그래서 네 수의 합 ≤ `itemCount`)
  - 가져오는 상한 `MAX_FETCH_ITEMS = 500`(가장 큰 곡 한도 150보다 넉넉, YouTube 쿼터 최대 11 단위). 그 뒤 항목 수(`itemCount − 가져온 수`)는 `skippedLimit`에 더한다
  - 비공개 판별: `videoOwnerChannelTitle` 없음 또는 `privacyStatus` ∈ {`private`, `privacyStatusUnspecified`} 또는 videoId 형식 틀림. `unlisted`는 가져온다
  - 기본 분류 이름 = 재생목록 제목 trim 후 앞 20자(빈 제목이면 `재생목록`). 같은 이름 분류가 있으면 409 `CONFLICT`(`POST /categories`와 같음) — 화면은 "기존 분류에 넣기"나 다른 이름으로
  - 빈 재생목록이라도 `newCategory`면 분류는 만든다(수는 모두 0)
- 자동 연동(설계 §4)은 `TODO(stub)` — M1-4가 `SharedFolderSync.resyncCategories`를 `import` 트랜잭션 끝에 연결

### 오류

| 상황 | 응답 |
| --- | --- |
| 토큰 없음 | 401 `UNAUTHORIZED` |
| `url` 없음·2000자 초과, YouTube 호스트 아님(`youtube.com`·`youtu.be`·하위 도메인만), `list` 없음·형식 틀림, `categoryId`·`newCategory:true` 둘 다/없음, `newCategory:false`만, `categoryName`을 `categoryId`와 같이, 빈 `categoryName`, `categoryId` UUID 아님 | 400 `INVALID_INPUT` (YouTube를 부르지 않음) |
| 남의·없는 `categoryId` | 404 `NOT_FOUND` |
| 새 분류인데 분류 칸 없음 | 403 `CATEGORY_LIMIT_EXCEEDED` + `detail{limit,used,tier,nextTier,nextLimit}`, 아무것도 등록 안 함(A4) |
| 새 분류 이름 중복 | 409 `CONFLICT` |
| 없는·비공개 재생목록(`playlists` `items:[]`, 또는 `playlistItems` 404/`playlistNotFound`) | 404 `PLAYLIST_NOT_FOUND` |
| 키 미설정 | 503 `YOUTUBE_UNAVAILABLE` |
| 그 밖 YouTube 오류(쿼터·키 오류·네트워크) | 502 `YOUTUBE_API_ERROR` |
