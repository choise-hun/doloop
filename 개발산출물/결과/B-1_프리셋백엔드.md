## 1. 구현 내용 요약

### 1-1. DB 마이그레이션 (`V9__presets_and_practice_parts.sql`)
1. **`song_presets` 테이블 신설**:
   - `id UUID PRIMARY KEY`, `user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE`
   - `song_id UUID NOT NULL REFERENCES songs(id) ON DELETE CASCADE`
   - `name TEXT NOT NULL`, `a NUMERIC(7,2) NOT NULL`, `b NUMERIC(7,2) NOT NULL`, `rate NUMERIC(3,2) NOT NULL DEFAULT 1.00`, `completed BOOLEAN NOT NULL DEFAULT false`
   - 복합 외래키 `FOREIGN KEY (user_id, song_id) REFERENCES songs(user_id, id) ON DELETE CASCADE`
   - 고유 인덱스 `UNIQUE (user_id, song_id, name)`: 곡당 동일 이름 프리셋 1개 보장
2. **`songs` 테이블 확장**:
   - `duration_sec INTEGER NULL`: 영상 전체 길이(초) 저장 (커버리지 계산 분모)
3. **`sessions` 테이블 확장**:
   - `part_stats JSONB NOT NULL DEFAULT '{}'::jsonb`: 파트별 연습 집계 (`{ "partName": { "name", "a", "b", "rate", "completed", "loops", "seconds" } }`)
   - `coverage_pct SMALLINT NOT NULL DEFAULT 0`: 곡 전체 대비 연습 커버리지 (0~100)
4. **`takes` 테이블 확장**:
   - `part_name TEXT NOT NULL DEFAULT ''`: 테이크 녹음 시 지정된 구간 프리셋 명칭
   - `completed BOOLEAN NOT NULL DEFAULT false`: 테이크 단위 구간 완료 플래그

### 1-2. Kotlin Exposed 스키마 & DTO (`Tables.kt`, `SongService.kt`, `SessionService.kt`, `TakeService.kt`)
1. `SongPresetsTable` 정의 및 `ALL_TABLES` 등록 (23개 ➔ 24개).
2. `SongsTable.durationSec`, `SessionsTable.partStats`, `SessionsTable.coveragePct`, `TakesTable.partName`, `TakesTable.completed` 컬럼 매핑.
3. DTO 확장:
   - `SongDto`: `durationSec: Int? = null` 추가 (15 ➔ 16개 필드).
   - `SongSessionDto` / `SessionWithSongDto`: `partStats: JsonElement?`, `coveragePct: Int` 추가.
   - `TakeDto`: `partName: String = ""`, `completed: Boolean = false` 추가 (12 ➔ 14개 필드).
   - 신규 `SongPresetDto`: `id, songId, name, a, b, rate, completed, createdAt, updatedAt`.
   - `SongDetailResponse`: `presets: List<SongPresetDto> = emptyList()` 포함.

### 1-3. 서비스 로직 및 엔드포인트
1. **구간 프리셋 CRUD (`SongRoutes.kt`, `SongService.kt`)**:
   - `GET /api/v1/songs/{songId}/presets`: 프리셋 목록 조회.
   - `PUT /api/v1/songs/{songId}/presets`: 프리셋 등록/수정. 동일 이름 저장 시 사용자가 분할 연습한 구간을 처리하기 위해 `a = min(old_a, new_a)`, `b = max(old_b, new_b)`로 누적 확장 병합 및 완료 상태 업데이트.
   - `DELETE /api/v1/songs/{songId}/presets/{presetId}`: 프리셋 삭제.
2. **연습 세션 저장 파트 통계 및 커버리지 연산 (`PracticeRoutes.kt`, `PracticeService.kt`)**:
   - `POST /api/v1/practice/save`에서 `partName`, `completed`, `durationSec` 파라미터 수신.
   - 세션의 `part_stats` jsonb에 파트별 누적(`seconds`, `loops`, `completed`, `rate`, `a`, `b`) 병합.
   - 곡의 `duration_sec` 기준 또는 연습된 전체 구간 대비 총 순수 구간 길이의 합으로 `coverage_pct` (0~100%) 자동 산출.
3. **테이크 완료 토글 API (`TakeRoutes.kt`, `TakeService.kt`)**:
   - `PATCH /api/v1/takes/{takeId}/complete`: `completed: Boolean` 토글.
   - 테이크에 연결된 `partName`이 있고 곡에 동일한 프리셋이 존재할 경우 프리셋의 `completed` 상태도 동기화 갱신.
4. **드라이브 마이그레이션 select 버그 수정**:
   - `TakeService.migrateToDrive`에서 제한된 컬럼 select로 인한 `partName is not in record set` 예외를 `TakesTable.selectAll()`로 수정하여 완전 해결.
