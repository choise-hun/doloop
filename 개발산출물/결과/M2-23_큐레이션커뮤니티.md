## 3. 명세와 달라진 점

1. **`communityErrorKey`의 `NOT_FOUND` → `folder.err.gone` 매핑 (`frontend/src/lib/community.mts:183-185`):** 명세 §5 에러 표는 `404 FOLDER_NOT_FOUND | FOLDER_HIDDEN`을 `folder.err.gone`으로 지정했으나, 서버 및 E2E 픽스처의 일반 `404 NOT_FOUND` 응답도 동일하게 안내하기 위해 `code === 'FOLDER_NOT_FOUND' || code === 'FOLDER_HIDDEN' || code === 'NOT_FOUND'`를 `folder.err.gone`으로 매핑함.
2. **`MySharesPanel.tsx`의 행별 정렬 그룹 이름 `shareSw` / `shareSw<n>` (`frontend/src/components/community/MySharesPanel.tsx:204`):** 명세 §1 배치 약속 표의 맞춤 그룹 이름은 `shareSw:center-y@481`이나, 여러 분류 행이 동시에 렌더링될 때 서로 다른 행의 세로 중심이 묶여 비교되지 않도록 첫 행(`idx === 0`)은 `shareSw:center-y@481`, 이후 행은 `shareSw${idx}:center-y@481`(`shareSw1:center-y@481` 등)으로 행마다 그룹 이름을 분리함.
