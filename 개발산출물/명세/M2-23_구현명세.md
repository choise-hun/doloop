async function toggleLike(f: Folder) {
  if (busy.current.has(f.id)) return; busy.current.add(f.id);
  const prev = { liked: f.likedByMe, count: f.likeCount };
  patchFolder(f.id, { likedByMe: !prev.liked, likeCount: prev.count + (prev.liked ? -1 : 1) });

  catch (e) { patchFolder(f.id, { likedByMe: prev.liked, likeCount: prev.count }); setMsg(communityErrorKey(e)); }
  finally { busy.current.delete(f.id); }
}

## 7. 개인정보처리방침 5절 (`<h2 id="privH5">5. 커뮤니티 공개 범위</h2>`, `<ul>` 항목 그대로)

1. 커뮤니티 기능은 선택 사항이며, 사용자가 직접 공개한 항목만 다른 사용자에게 보입니다.
2. 공개 폴더: 사용자가 정한 공개 제목과 커뮤니티 이름, 곡의 YouTube 영상 ID·영상 제목·채널명, 추천 구간·배속·순서가 공개됩니다. 곡 메모·연습 상태·사용자가 고친 곡 제목은 공개되지 않습니다.
3. 자동 연동을 켠 폴더는 원본 분류가 바뀔 때 공개본도 바로 바뀝니다. 설정에서 끄면 마지막 공개본이 남고, 비공개로 바꾸면 내려갑니다.
4. 학습 기록 공유를 켜면 최근 12주의 날짜별 연습 시간, 연속 연습 일수, 이번 주 합계, 오늘 연습한 곡(YouTube 영상 제목·채널명)과 시간·반복 수가 공개됩니다. 연습 메모는 공개되지 않습니다.
5. 이메일·로그인 계정 이름·닉네임은 공개되지 않으며, 커뮤니티에서는 사용자가 정한 커뮤니티 이름만 보입니다.
6. AI 학습 노트, 코드 진행, 녹음 파일은 어떤 경우에도 공개되지 않습니다.
7. 좋아요·팔로우 수는 개수만 공개됩니다. 신고 내용은 운영자만 봅니다. 유료 플랜이 끝나면 공개 폴더와 학습 기록 공유가 멈춥니다.
