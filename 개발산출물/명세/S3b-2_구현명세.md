## 4. 계약 추가분

### 4.1 `AudioSignature`

```kotlin
object AudioSignature { fun matches(mime: String, bytes: ByteArray): Boolean }
```

| mime | 참 조건(앞부분 바이트) |
| --- | --- |
| `audio/mp4` | `bytes[4..7] == "ftyp"` |
| `audio/webm` | `1A 45 DF A3` |
| `audio/ogg` | `"OggS"` |
| `audio/mpeg` | `"ID3"` 또는 `b0 == 0xFF && (b1 & 0xE0) == 0xE0` |
| `audio/wav` | `"RIFF"` + `bytes[8..11] == "WAVE"` |
| `audio/aac` | `b0 == 0xFF && (b1 & 0xF6) == 0xF0`(ADTS) |
| 그 밖·길이 부족 | 거짓 |

### 4.2 업로드 요청 검증 순서

`Content-Length` > 10,485,760 + 65,536 → 413 `ATTACHMENT_LIMIT_EXCEEDED`(detail `{kind:"size",limit:10485760}`) → `takeId` 없음·형식 오류 400 `INVALID_INPUT` → tx1 검사(S3b-1 §4.5 순서, drive 아님 409 `ATTACHMENT_UPLOAD_INVALID`) → 파일 파트 없음 400 → 읽은 길이 > 한도 409 size → D5 → `upload`(실패 502) → `uploaded` 전환. tx1 뒤 실패는 S3b-1 §5의 보상(행 삭제 + 보류 행 즉시 정리)을 그대로 쓴다. 저장소 미설정 503.
