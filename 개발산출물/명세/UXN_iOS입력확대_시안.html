iOS 입력 후 화면 확대 문제

배치·입력창 높이·버튼은 유지하고, URL 입력 글자만 14 → 16px로 보정합니다.

현재 · 14px 비교 기준

영상 추가

작은 입력 글자 → iOS 자동 확대 가능. 현재 앱은 핀치 복원도 제한됨.

A · 입력 16px + 핀치 허용 (추천)

영상 추가

빈 플레이어·곡 목록 서랍의 URL 입력을 모두 16px로. 입력 자동 확대의 원인을 줄이고, 사용자가 확대했을 때 두 손가락으로 되돌릴 수 있도록 iOS native 핀치를 허용합니다.

영상 iframe 자체 제스처는 외부 플레이어 동작을 따릅니다.

B · 입력 16px만 보정

영상 추가

동일한 두 URL 입력만 16px로. 앱의 핀치 제한은 현재대로 유지합니다. 다른 작은 입력에서 발생하는 확대나 수동 확대 복원은 해결 범위에 포함되지 않습니다.

시안에서는 글자/배치를 비교합니다. 실제 앱의 키보드 자동 확대·핀치·스와이프 충돌은 선택 후 iPhone native 테스트로 확인합니다. 최대 배율 고정, blur 시 강제 확대 초기화는 사용하지 않습니다.
