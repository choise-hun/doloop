## 2. 시그니처

### 2.1 `service/TakeService.kt` 확장 (package `ulevelp.service`)

```kotlin
data class DriveTakeRegisterInput(
    val songId: UUID,
    val date: LocalDate,
    val recordedAt: OffsetDateTime,
    val a: BigDecimal?,
    val b: BigDecimal?,
    val rate: BigDecimal?,
    val durationSec: Int,
    val mime: String,
    val sizeBytes: Long,
    val driveFileId: String
)

data class TakeDownloadData(
    val bytes: ByteArray,
    val mime: String,
    val filename: String
)

class TakeService(...) {
    // 기존 upload, signedUrl, delete 유지

    /**
     * POST /api/v1/takes (Content-Type: application/json, storage="drive")
     * - storageClient가 null 이어도 동작한다.
     * - 노션 실시간 연동(notion_sync.enabled == true)이 켜져 있으면 409 NOTION_SYNC_CONFLICT 거부.
     * - 곡 소유 확인 -> ensureSession(0초 세션 보장) -> TakesTable.insert(storage="drive", storageKey=driveFileId).
     * - 기본 스토리지 쿼터(take_quota_bytes)를 검사하거나 차감하지 않으며, take는 sync_outbox에 적재하지 않는다.
     */
    suspend fun registerDriveTake(userId: UUID, input: DriveTakeRegisterInput): TakeDto

    /**
     * GET /api/v1/takes/{takeId}/download
     * - 기존 Supabase Storage 녹음의 원본 바이트를 내려준다 (브라우저가 Drive로 이전할 때 사용).
     * - storage == "drive" 이면 400 INVALID_INPUT ("이미 Google Drive에 저장된 녹음입니다.").
     */
    suspend fun downloadBytes(userId: UUID, takeId: UUID): TakeDownloadData

    /**
     * POST /api/v1/takes/{takeId}/migrate-drive
     * - 노션 실시간 연동이 켜져 있으면 409 NOTION_SYNC_CONFLICT 거부.
     * - 기존 storage == "supabase" 인 녹음의 storageKey를 StorageTrashTable에 적재(trashIds 반환)하고,
     *   TakesTable 행을 storage = "drive", storageKey = driveFileId 로 UPDATE 한다.
     * - 이미 storage == "drive" 인 녹음이면 StorageTrashTable 적재 없이 storageKey = driveFileId 만 갱신한다.
     */
    suspend fun migrateToDrive(userId: UUID, takeId: UUID, driveFileId: String): Pair<TakeDto, List<Long>>

    companion object {
        val DRIVE_FILE_ID_REGEX = Regex("^[A-Za-z0-9_-]{5,200}$")
    }
}
```

### 2.2 `routes/TakeRoutes.kt` 확장

- **`POST /api/v1/takes` 분기 수정:**
  - `if (call.request.isMultipart()) { ... 기존 multipart 업로드 로직 그대로 ... }`
  - `else if (call.request.contentType().withoutParameters() == ContentType.Application.Json) { ... Drive JSON 등록 로직 ... }`
  - 그 외 `Content-Type`이면 `throw InvalidInputException("multipart/form-data 또는 application/json 요청이 필요합니다.")`.
- **`GET /api/v1/takes/{takeId}/download` 추가:**
  - `val data = takeService.downloadBytes(user.id, takeId)`
  - `call.response.headers.append(HttpHeaders.CacheControl, "no-store")`
  - `call.respondBytes(data.bytes, ContentType.parse(data.mime), HttpStatusCode.OK)`
- **`POST /api/v1/takes/{takeId}/migrate-drive` 추가:**
  - `val body = call.receiveJsonObject()`
  - `val driveFileId = body.requireString("driveFileId", 200)` (`!TakeService.DRIVE_FILE_ID_REGEX.matches(driveFileId)`이면 `InvalidInputException("driveFileId 형식이 올바르지 않습니다.")`)
  - `val (takeDto, trashIds) = takeService.migrateToDrive(user.id, takeId, driveFileId)`
  - `if (trashIds.isNotEmpty()) storageTrashService.purge(trashIds)`
  - `call.respond(HttpStatusCode.OK, TakeEnvelope(ok = true, take = takeDto))`

### 2.3 `public/drive.js` (`window.ULDrive`)

Google OAuth 액세스 토큰은 **인메모리 클로저 변수(`accessToken`, `tokenExpiresAt`)에만 보관**하며 `localStorage`나 `sessionStorage`에는 절대 저장하지 않는다(`NFR-SEC-3`).

```js
window.ULDrive = (function () {
  // 공개 메서드:
  // - requestToken(opts)           -> Promise<string> (GIS google.accounts.oauth2.initTokenClient 호출)
  // - ensureFolder(preferredId)    -> Promise<string> ('ULeveLP 녹음' 폴더 확인 또는 생성 후 folderId 반환)
  // - uploadBlob(blob, name, mime, folderId) -> Promise<string> (5MB 이하 multipart, 5MB 초과 resumable 업로드 후 driveFileId 반환)
  // - uploadTake(meta, blob)       -> Promise<TakeDto> (ensureFolder -> uploadBlob -> ULData.takes.registerDrive)
  // - fetchMediaObjectUrl(fileId)  -> Promise<string> (Drive API alt=media로 받아 URL.createObjectURL(blob) 반환)
  // - enableDriveStorage()         -> Promise<MeResponseDto> (폴더 확보 후 PATCH /api/v1/me { storageProvider: 'drive', driveFolderId })
  // - disableDriveStorage()        -> Promise<MeResponseDto> (PATCH /api/v1/me { storageProvider: 'supabase' })
  // - migrateAllToDrive(onProgress)-> Promise<{ migrated: number, skipped: number }>
  // - clearToken()                 -> void (로그아웃/계정 전환 시 인메모리 토큰 초기화)
})();
```
- **5MB 이하 vs 5MB 초과 업로드 규칙 (`FR-DRIVE-2`):**
  - `blob.size <= 5 * 1024 * 1024` (5,242,880B 이하):
    `POST https://www.googleapis.com/upload/drive/v3/files?uploadType=multipart&fields=id`로 JSON 메타데이터(`{ name, parents: [folderId], mimeType: mime }`)와 오디오 바이트를 `multipart/related`로 전송한다.
  - `blob.size > 5 * 1024 * 1024`:
    1) `POST https://www.googleapis.com/upload/drive/v3/files?uploadType=resumable`에 JSON `{ name, parents: [folderId], mimeType: mime }`와 `X-Upload-Content-Type`, `X-Upload-Content-Length` 헤더를 보내 응답 헤더 `Location`을 얻는다.
    2) `Location` URL이 `https://www.googleapis.com/`으로 시작하는지 검증한 뒤 `PUT`으로 `blob`을 전송해 `{ id }`를 받는다.

## 5. 처리 순서·트랜잭션 경계

### 5.1 `TakeService.registerDriveTake(userId, input)`
1. 단일 DB 트랜잭션 안에서:
   - `SongsTable`에서 `(id eq input.songId) and (userId eq userId)` 존재 확인(없으면 `404 NOT_FOUND`).
   - `NotionSyncTable`에서 `(userId eq userId) and (enabled eq true)`이면 `409 NOTION_SYNC_CONFLICT`.
   - `val sessionRes = ensureSession(userId, input.songId, input.date, input.rate, input.a, input.b)`.
   - `TakesTable.insert` (`storage = "drive"`, `storageKey = input.driveFileId`, `sizeBytes = input.sizeBytes`).
   - `TakeDto` 반환 (`takeUsedBytes`는 `storage = 'supabase'`만 합산하므로 클라우드 스토리지 사용량 증가 `0`).

### 5.2 `TakeService.migrateToDrive(userId, takeId, driveFileId)`
1. **트랜잭션 1 (DB 갱신 및 `storage_trash` 적재):**
   - `TakesTable`에서 `(id eq takeId) and (userId eq userId)` 조회(없으면 `404 NOT_FOUND`).
   - `NotionSyncTable`에서 `(userId eq userId) and (enabled eq true)`이면 `409 NOTION_SYNC_CONFLICT`.
   - 기존 `row[TakesTable.storage] == "supabase"`이면 `oldKey = row[TakesTable.storageKey]`를 `StorageTrashTable`에 INSERT해 `trashIds`에 담는다.
   - `TakesTable.update({ (id eq takeId) and (userId eq userId) }) { it[storage] = "drive"; it[storageKey] = driveFileId }`.
2. **트랜잭션 밖 (`TakeRoutes.kt`):**
   - `if (trashIds.isNotEmpty()) storageTrashService.purge(trashIds)`를 호출해 Supabase Storage 원본 파일을 즉시 삭제한다.

## 9. 금지 사항

- Google OAuth 액세스 토큰(`drive.file`)을 `localStorage`나 `sessionStorage`에 저장하지 않는다(`NFR-SEC-3`: 오직 `drive.js` 인메모리 변수에만 보관하고 로그아웃·계정 전환 시 즉시 지운다).
- `POST /api/v1/takes`에서 `storageClient == null` 검사를 JSON 분기보다 앞에 두어 Drive 메타 등록까지 `503 STORAGE_UNAVAILABLE`로 막히게 하지 않는다(저장소 설정 검사는 `isMultipart()` 분기 안에서만 수행).
- 다음 step(KZ-1)을 이어서 진행하지 않는다.
