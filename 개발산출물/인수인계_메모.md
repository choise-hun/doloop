## 4. 다른 PC에서 시작할 때

```bash
git clone https://github.com/choise-hun/ULevelP.git && cd ULevelP
npm ci && npx playwright install chromium
cp .env.example .env            # Supabase·DB 값 채우기 (값은 Secret Manager/Supabase 대시보드)
npm test && ./gradlew test      # 단위 테스트
npm run build && ULP_UI=spa node server.js   # React 화면 확인 (vite dev는 CSP 때문에 화면 확인에 안 씀)
```

- 배포(지금은 로컬에서만 가능, gcloud Owner 계정 로그인 필요):
```bash
SHA=$(git rev-parse --short origin/main)
IMAGE_URI=asia-northeast3-docker.pkg.dev/ulevelp/ulevelp/server:$SHA
docker buildx build --platform linux/amd64 -t "$IMAGE_URI" --push .    # main을 체크아웃한 상태에서
GCP_PROJECT_ID=ulevelp RUNTIME_SA_EMAIL=ulevelp-runtime@ulevelp.iam.gserviceaccount.com \
CRON_SA_EMAIL=ulevelp-cron@ulevelp.iam.gserviceaccount.com \nPUBLIC_APP_URL=https://ulevelp-d5ympfsmfq-du.a.run.app/ bash scripts/deploy-cloudrun.sh "$IMAGE_URI"   # PUBLIC_APP_URL 빼면 Pages로 되돌아감
```
- 함정
  - Apple Silicon은 `--platform linux/amd64` 필수. `--builder default`를 붙이면 buildx 컨텍스트 오류
  - zsh에선 `G="--region … --project …"; gcloud … $G`가 단어 분리되지 않는다. bash 배열이나 직접 입력
  - `~/.zshrc`의 `alias git="LANG=en_GB git"`이 Docker Desktop 블록과 한 줄로 붙어 깨졌던 적이 있다(2026-11-03 수정). 다른 PC에서도 `alias git`을 확인
  - PR을 올린 뒤 같은 브랜치에 커밋을 더 넣기 전에 머지됐는지 확인(`gh pr view <n> --json state`). PR #47 머지 후에 커밋을 더 올려서 #48로 다시 올린 적이 있다
