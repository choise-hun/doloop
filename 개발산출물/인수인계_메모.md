## 4. PC별 함정

- **Mac 계정·config 이전 체크리스트(2026-11-11 win에서 config를 choise-hun으로 이전) — 2026-11-12 Mac에서 remote·gh 두 계정·M-019 반영 확인. 새 Mac을 설정할 때만 참고:**
  1. `cd ~/config && git remote set-url origin https://github.com/choise-hun/config.git` — 이력이 다시 써져서 `git pull`이 아니라 아래 3번처럼 새로 받는다
  2. `gh auth login`을 `choise-hun`, `Hunseokc` 두 계정 모두 실행(`gh auth status`로 확인). 기본 활성은 choise-hun
  3. 이력이 달라 pull 불가 → `mv ~/config ~/config.old && git clone https://github.com/choise-hun/config.git ~/config` (미푸시 변경이 없는지 먼저 확인)
  4. `git -C ~/config config user.name choise-hun` · `git -C ~/config config user.email 355205251+choise-hun@users.noreply.github.com`
  5. 이전한 레포(doloop 등)의 로컬 user.email도 같은 값으로. `~/config` SessionStart 훅이 새 URL로 pull 되는지 확인
  6. Hunseokc 레포(team·ax_class_semiproject·ULevelP)에서만 `gh auth switch -u Hunseokc` 후 작업, 끝나면 `gh auth switch -u choise-hun`
