## 4. 이 프로젝트에서 배운 것

- 화면 확인은 `npm run build && ULP_UI=spa node server.js`(vite dev는 CSP 때문에 화면 확인에 안 씀). e2e는 서버를 백그라운드로 띄운 뒤 `npx playwright test …`
- gradle 증분 컴파일이 `FileNotFoundException … .class`로 깨지면 `./gradlew compileKotlin compileTestKotlin --rerun-tasks`
- Ktor CORS는 거부(403) 뒤에도 파이프라인을 끝내지 않는다 → `Main.kt`에서 CORS 뒤 `Call` 단계 finish 인터셉터(FX-1)
- Cloud Run 뒤에서는 forwarded header를 처리해야 같은 출처 요청이 CORS 403이 안 난다(#46 `XForwardedHeaders`)
- Playwright: 서버 응답 뒤에만 UI를 바꾸면 `check()`가 실패 → 낙관적 반영 + 실패 시 되돌림. `getByLabel`은 비슷한 라벨이 있으면 `{ exact: true }`
- PR을 올린 뒤 같은 브랜치에 커밋을 더 넣기 전에 머지 여부 확인(`gh pr view <n> --json state`) — #47 머지 후 커밋해 #48로 다시 올린 적 있음
- 옛 연습실 엔진(`voicing.mjs` `genVoicings`)은 재즈식 3~4음 보이싱 전용: 같은 음 이름 한 번만(`used`), 기본 `lo: 1`(개방현 없음)·`maxNotes: 4` → F 바레·오픈 코드가 어떤 옵션으로도 안 나온다(CH-2c 계기)
- CI `Detect code changes`(#84): 문서(`*.md`·`docs/`·`개발산출물/`)만 바꾼 PR은 테스트를 건너뛴다. 코드가 있는 PR에 문서만 추가 push하면 **직전 커밋 `CI ok`가 성공일 때만** 건너뜀(진행 파일·결과 기록 push는 1분 안에 끝남). 직전 실행이 취소·실패면 전부 다시 돈다
- 운영 배포 후에는 `gcloud run services describe ulevelp --region asia-northeast3 --project ulevelp --format="value(status.latestReadyRevisionName,spec.template.spec.containers[0].image)"`로 이미지 SHA를 이 메모 §1에 적는다(운영 ≠ main을 놓치지 않게)

## 6. 새 PC에서 시작할 때

```bash
git clone https://github.com/choise-hun/ULevelP.git && cd ULevelP
npm ci && npx playwright install chromium
cp .env.example .env            # Supabase·DB 값 채우기 (값은 Secret Manager/Supabase 대시보드)
npm test && ./gradlew test      # 단위 테스트
npm run build && ULP_UI=spa node server.js   # React 화면 확인
```

- 저장소 밖에서 손으로 옮길 것: `.env`, `gh auth login`, `gcloud auth login`(ulevelp Owner 계정), Docker Desktop 로그인
- 배포(지금은 로컬에서만, main을 체크아웃한 상태에서):

```bash
SHA=$(git rev-parse --short origin/main)
IMAGE_URI=asia-northeast3-docker.pkg.dev/ulevelp/ulevelp/server:$SHA
docker buildx build --platform linux/amd64 -t "$IMAGE_URI" --push .
GCP_PROJECT_ID=ulevelp RUNTIME_SA_EMAIL=ulevelp-runtime@ulevelp.iam.gserviceaccount.com \
CRON_SA_EMAIL=ulevelp-cron@ulevelp.iam.gserviceaccount.com \
bash scripts/deploy-cloudrun.sh "$IMAGE_URI"   # PUBLIC_APP_URL 기본값은 Cloud Run(#55)
```
