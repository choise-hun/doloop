## 4. 사용자 결정 대기 (WF-2 착수 조건)

1. 녹음 섹션 배치: **A안**(상자 둘 유지) / **B안**(한 줄, 녹음 맨 오른쪽) / **C안**(한 줄, 저장 맨 오른쪽) — 시안에서 상태 단추를 눌러 비교
2. 화면 폭: **가**(폭 상한 올리기, 추천) / **나**(크게 보기 전환 버튼) / 가+나 / 그대로
3. 팝오버가 뜨는 방향(시안은 위쪽 — 타임라인을 잠깐 가린다. 아래쪽도 가능)은 구현 때 스크린샷으로 정한다
