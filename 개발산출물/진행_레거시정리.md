## 1. 목표와 근거

React SPA(`frontend/src/**`) 전환(R0~R3, RZ-3)과 화면 개편(M2)·다국어(L1)가 모두 완료되었으나, 저장소와 CI에는 초기 롤백용으로 남겨 둔 구 바닐라 화면(`public/*.html` 8개, `public/*.js` 12개, `public/*.css` 3개, `public/lib/*.js` 2개)과 `ULP_UI=legacy` 분기가 남아 있다. 이로 인해:
1. 모든 코드 PR마다 CI `e2e` 잡이 `legacy`·`spa` 2개 매트릭스로 중복 실행되어 CI 시간이 2배로 든다(`.github/workflows/ci.yml:140-169`).
2. `Main.kt:88-89`·`scripts/deploy-cloudrun.sh:31`·`.github/workflows/deploy-cloudrun.yml:44`의 기본 `ALLOWED_ORIGINS`에 더 이상 API를 호출하지 않는 `https://choise-hun.github.io`(이동 페이지)와 개발용 `http://localhost:3000`이 남아 있다(`인수인계_메모.md` §2-4 ①, `:47`).
3. 구 화면(`public/*`)과 React 화면을 동시에 검사하는 단위/E2E 테스트 때문에 유지보수 비용이 이중으로 발생한다.

따라서 **2개 step(`LG-1` 서버·배포·CI 전환 → `LG-2` `public/` 레거시 파일 삭제 및 테스트 정리)**으로 나누어 안전하게 정리한다.
