## 4. 단계별 실행 명령 (Git Bash)

```bash
npm ci                                   # 처음 한 번
npm test                                 # 단위(node --test test/*.test.js)
npm run build                            # tsc --noEmit && vite build
# 화면 확인·e2e: 서버를 백그라운드로 띄우고
ULP_UI=spa node server.js &              # 3000번. 이미 떠 있으면 그대로 쓴다(EADDRINUSE)
npx playwright test test/e2e/layout/     # 정렬 검사 전체
npx playwright test test/e2e/layout/shell.spec.js          # W-1
LAYOUT_SHOTS=1 npx playwright test test/e2e/layout/chords.spec.js   # 스크린샷 → test-results/layout-shots/
gh pr checks --watch
```

- PowerShell에서는 `ULP_UI=spa …` 접두 실행이 안 된다 → Git Bash
- Windows에서 `npm test`의 CH-2c-1-1·CH-2c-3-2 실패는 CRLF 때문(CI 무관, `인수인계_메모.md` §5). 결과 파일에 "기존 CRLF 실패 2건"으로 적고 넘어간다
