## 실행·검증·게시 결과

- 문서 반영 완료. 인라인 Python 검증: 변경 10개 문서 UTF-8(BOM 없음)/LF·후행 공백·코드 블록 짝·Markdown 링크 PASS. 두 저장소 git diff --check PASS. 탐색 §1.1의 프로젝트/보관본/초기화 템플릿 3곳 일치, 테스트 규칙 바이트 일치 PASS.
- 검증 도구 보정: 초기 PowerShell→Python 파이프의 한글 인코딩 오류는 쓰기 전 발생. 이후 OutputEncoding UTF-8로 실행했다. subprocess의 cp949 출력 해석 오류는 python -X utf8로 보정해 전체 검증을 오류 없이 재실행했다. 실패한 실행을 최종 검증 근거로 사용하지 않았다.
- 활성 제품 폴더의 대상 규칙 3개는 시작 시 SHA-256과 대조해 타 변경 없음 확인 후 검증된 파일만 적용했다. CH-B 제품·테스트·인수인계 변경은 수정하거나 커밋하지 않았다.
- 프로젝트 변경 커밋 67e7ddf, PR [#144](https://github.com/choise-hun/doloop/pull/144). CI [42546696129](https://github.com/choise-hun/doloop/actions/runs/42546696129): Detect code changes·CI ok success, 문서 전용으로 제품 테스트 skip.
