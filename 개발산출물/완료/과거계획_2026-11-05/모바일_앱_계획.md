# ULeveLP 모바일 앱 개발 계획 핵심 요약 (v1.3)

- **갱신일:** 2026-11-05
- **반영 사항:** ① 작업 우선순위 확정(모바일·Pro·AI 노트 UX 개편 선행 → 다국어 일괄 마감), ② AI 노트 `BETA` 명시·UX 최적화·코드 진행 공유 및 글로벌 캐시 폐기, ③ Pro 전용 유튜브 재생목록 일괄 추가·곡 폴더/학습 기록 공유 커뮤니티·유명인 연습 곡 쇼케이스·스포티파이형 연습곡 큐레이션 반영
- **상세 기준 문서:** `계획/앱_명세.md` (v1.3), `계획/언어지원_계획.md` (v2.1)

### 1. 두 작업 중 무엇을 먼저 수행할지 결정: **기능·UI 개편(Phase M) 선행 → 다국어(`묶음 L`) 일괄 마감**

1. **이유 1 (번역·레이아웃 이중 작업 원천 제거):** 이번에 추가·수정되는 **AI 노트 Beta UX 개편, 유튜브 재생목록 일괄 추가, 공유 커뮤니티(곡 폴더·학습 기록), 유명인 연습 리스트, 스포티파이형 큐레이션**은 프런트엔드 화면과 문구가 가장 크게 바뀌는 작업입니다. 다국어(`L1-2`)를 먼저 해버리면 새 기능을 넣을 때마다 `ko·en·ja` 3개 국어 사전과 390px 모바일 줄바꿈 검사를 매번 다시 해야 합니다.
2. **이유 2 (DB 스키마 통합):** `Phase M1-1`(`V5__tiers_credits_and_community.sql`)에서 `profiles` 테이블에 티어·크레딧·크리에이터 배지 컬럼을 넣을 때 `locale`(`'ko' | 'en' | 'ja'`) 컬럼만 한 줄 함께 넣어두면 마이그레이션이 한 번에 깔끔하게 정리됩니다.
3. **확정 실행 순서:**
   - **1순위:** `GA-3`(실영상 확인 마무리) → **`Phase M1` & `M2`**(티어·크레딧·재생목록 일괄 추가·큐레이션/커뮤니티·AI 노트 Beta UX 개편) → **`Phase M0` & `M3`**(Capacitor 앱 래핑·하단 탭 바·네이티브 기능)
   - **2순위:** 모든 화면과 문구가 확정된 직후 **`묶음 L`(`L1-1` → `L1-2`)**로 한·영·일 3개 국어를 한 번에 적용 → **`Phase M4`**(인앱 결제·스토어 출시)

### 2. AI 노트 관련 수정 반영 (`앱_명세.md` 3.1절 & 4절)

| 항목 | 확정 설계 및 반영 내용 |
| :--- | :--- |
| **1. `BETA` 기능 명시** | • 상단/하단 메뉴 `NOTES`, `NotesPage.tsx` 헤더, `CHORDS`의 `코드 진행 영상 분석` 탭에 **`BETA` 배지(`--radius-pill`)** 부착<br>• *"AI 분석(Beta)은 영상의 음향·화질에 따라 일부 코드·보이싱이 실제와 다를 수 있으며, 개인 학습 참고용으로만 보관됩니다"* 안내 문구 고정 노출 (과금 클레임·환불 분쟁 예방) |
| **2. AI 노트 UI·UX 최적화** | • **입력 폼 경량화:** 첫 화면에는 `[유튜브 링크 + 핵심 태그(기본 '화성') + 예상 크레딧 + 분석 요청]`만 노출하고, `구간 지정(startSec~endSec)`·`메모`는 `[+ 구간 지정 · 메모 옵션]` 접이식 토글로 정리<br>• **원탭 재시도:** 실패 시 원인(`jobError.mts`) 안내와 함께 기존 입력값을 유지한 채 구간만 줄여 바로 재시도하는 동선 제공<br>• **상세 화면(`NoteDetailPage`) 액션 바:** 상단에 `[▶ 플레이어로 열기]` · `[마크다운 복사]` · `[코드 진행 수집]`을 한 줄 배치하고 모바일 지판·건반 SVG 가로 스와이프 최적화 |
| **3. 코드 진행 공유 & 글로벌 캐시 전면 폐기** | • **개인정보 및 저작권(KOMCA) 보호:** 사용자의 메모·시청 이력이 담길 수 있는 글로벌 분석 캐시(`shared_analysis_cache`)와 `CHORDS` 코드 진행 공유(2차 공개 레퍼런스) 계획을 **전면 폐기**<br>• `notes`(학습 노트)와 `progressions`(코드 진행 모음)는 **100% 본인 계정 전용 보관함(Private Vault)**으로만 격리 운영 |

### 3. Pro 핵심 기능 및 공유 커뮤니티 · 스포티파이형 큐레이션 반영 (`앱_명세.md` 2.1절 & 2.2절)

| 구분 | 기능 상세 및 무료(`Free`) / 유료(`Pro` · `Pro+`) 차별화 |
| :--- | :--- |
| **1. 유튜브 재생목록(`PL...`) 한 번에 집어넣기 (`Pro` 전용)** | • 플레이어 곡 추가 시 유튜브 재생목록 URL(`list=PL...`)을 붙여넣으면 YouTube API(`playlistItems.list`)로 전체 곡 목록을 불러와 **재생목록 이름의 분류 폴더 자동 생성 + 보유 한도(Pro 100곡 / Pro+ 150곡) 내 일괄 등록** (`POST /api/v1/songs/import-playlist`)<br>• 무료 회원은 단일 영상 추가(최대 10곡)만 가능하며 재생목록 입력 시 Pro 업그레이드 안내 노출 |
| **2. 공유 커뮤니티 (곡 목록 폴더 & 학습 기록만 공유)** | • **공유 허용:** ① 유튜브 공개 `videoId`와 추천 연습 구간(`a`~`b`)·배속(`rate`)으로 구성된 **곡 분류 폴더(`categories`)**, ② **학습 기록(`sessions` 기반 주간 스트릭·연습 시간·반복 횟수 통계)**만 공유<br>• **공유 금지:** **학습 노트(`notes`), 코드 진행(`progressions`), 녹음 오디오(`takes`)는 저작권·개인정보 보호를 위해 공유 원천 차단**<br>• **Pro 혜택:** 내 곡 폴더를 커뮤니티에 공개하거나, 타인/유명인의 공유 폴더를 **[1클릭으로 내 플레이어에 통째로 가져오기]** 가능 (무료 회원은 열람 및 10곡 한도 내 개별 곡 담기만 가능) |
| **3. 유명인(크리에이터·아티스트) '현재 연습 중인 곡' 메인 쇼케이스** | • 인증된 유명인/크리에이터(`profiles.is_creator = true`)가 현재 `연습 중`(`practicing`)인 곡과 연습 구간(`a`~`b`, `rate`)을 공개하면, 홈 및 플레이어 메인 상단 **[🔥 지금 크리에이터가 연습 중인 곡]** 섹션에 실시간 노출<br>• 팬·일반 유저가 클릭 한 번으로 해당 아티스트와 똑같은 곡·구간·배속으로 연습 시작 가능 |
| **4. 운영자 추천 + 인기곡 큐레이팅 (스포티파이형 연습곡 탐색)** | • **운영자 추천 큐레이션 (`curated_playlists`):** 장르·난이도·주법별 추천 연습곡 리스트와 곡별 **추천 킬링파트 구간(`a`~`b`)·추천 배속**을 기본 세팅해 제공<br>• **실시간 인기 연습곡 Top 20:** 전체 사용자의 최근 7일/30일 연습 시간·등록 수를 익명 집계하여 가장 많이 연습 중인 곡과 하이라이트 구간을 스포티파이 차트처럼 노출 |
