# 디자인 규칙 (동네한권)

디자인 작업에 그대로 적용하는 규칙이다. 현재 결정과 기준 시안을 한곳에 모았다. 마지막 갱신: 2026-11-18 (하라 켄야 레퍼런스 수정안 — "글자·여백" 제안 섹션, 85:10:5 확장 제안, 검정 채움 규칙 통합안, "하라 켄야에서 가져온 것" 섹션 추가. 모두 채택 전).

- 결정 원문·토큰 표: [개발산출물/디자인_기준.md](개발산출물/디자인_기준.md)
- 기준 시안(후보 전환·명세 패널 포함): [방문_페이지_시안.html](개발산출물/시안/방문_페이지_시안.html)
- 결정 기록: [00 O-19~O-38](개발산출물/00_기획_원본.md), [C-13~C-21, C-48](개발산출물/스펙_변경_이력.md)
- 취향 프로필 원문: [색 배합 취향 프로필](https://claude.ai/artifact/Lm9GFd5c9xxVUZSAtyftWF)

규칙은 **확정**(그대로 지킨다)과 **보류**(정하지 않았으니 최소한으로만 적용)로 나뉜다. 후보를 고를 때의 규칙은 CLAUDE.md "시안 규칙"을 따른다.

## 원칙 (확정)
- 모던하고 차분하게. 배경은 콘크리트·회반죽 벽 같은 웜 그레이(웜 룩은 온도를 낮춰 중성에 가까운 톤), 따뜻한 간접조명 느낌. 나무 질감·나무색은 쓰지 않는다.
- 곡률·배색·형태는 Arne Vodder 사이드보드(슬라이딩 도어 색 블록, 렌즈형 손잡이, 아치)에서만 가져온다.
- 장황한 연출은 없다. 지도 → 도서관은 페이지가 바뀐 것을 알아볼 수 있는 전환(옆으로 밀림 + 배경·헤더 변화 + 방문 멘트 카드 한 줄)이면 충분하다. "입장했어요" 한 줄은 방문 횟수에 따른 멘트 카드로 바꿨다(C-55).
- 색과 곡률은 값을 직접 쓰지 않고 **토큰**으로 쓴다. 도서관 룩(M2, VISIT-07)이 토큰만 바꿔 끼운다. M1은 기본 룩(warm) 하나만 쓴다.
- 강조는 색을 더하지 않고 굵기·명도로 한다. 흐릿하게 존재해야 하는 표기(태그 등)는 배경을 빼고 투명도를 낮춘다.

### 룩 4종 토큰

| 배경 `bg` | #CDCDCB | #E1E1DE | #E4E2DB | #CDCDCB |

| 채움1 `fill1` (대표색) | #FB5102 | #E9C970 | #6E5140 | #35557F |
| 채움2 `fill2` | #F2F2EF | #EDC9A9 | #C88A56 | #D2B48C |

| 진한색 `ink-strong` (버튼·받침) | #1C1E2A | #2E333F | #332A27 | #002147 |

- 본문 글자 #1D1D1F. 보조 글자 = `bg`를 50% 어둡게, 구분선 = `bg`를 13% 어둡게.
- 채움 위의 글자색은 자동으로 고른다(채움색과 흰색·어두운색 중 대비가 큰 쪽).
- `paper`는 원래 카드 흰색을 `bg` 쪽으로 40% 눌러 순백 느낌을 없앤 값이다.
- **웜 온도**: warm은 -20%, toffee는 -30%. 모든 색의 R를 24×n 낮추고 B를 24×n 올린다(warm 4.8, toffee 7.2, 0~255 제한). 모던(주황)은 제외, Oxford는 이미 차가워 적용하지 않는다.
- 웜 배경 #E1E1DE는 R < G ≈ B라 "붉은기가 도는 웜 뉴트럴"(취향 프로필)보다 중성 쪽이다. 사용자가 균형이 가장 좋다고 골랐다.
- Oxford의 큰 면은 #002147보다 한 단계 밝은 #35557F, #002147은 버튼·받침에만 쓴다. 모던은 튀어도 된다.
- 색 대비는 시안으로 사용자가 확정한다. 접근성(색약 등)은 확정 후 한 번 수치로 확인한다.
- **2026-11-17 확정(홈 시안 C, 사용자 결정)**: toffee `fill2` #C88A56(캐러멜 앰버)·`fill3` #7E8C7D(올리브 세이지)로 분리해 배경 표면과 겹침을 없앴다. Oxford는 `bg`·`surface2`·`surface3`·`cream`·`paper`를 모던과 같은 무채색으로 통일하고 `fill3`를 #7A93AC로 조정했다. 시안은 외부(웹 Gemini)에서 확인해 확정했고 이 문서가 기록이다. 전체 근거는 [개정 통합본](개발산출물/명세/DESIGN_개정통합본_홈중심_조형시스템.md).
- **파생 색(시안 C 파사드·릴리프)**: `mix(A,B,w)=A×w+B×(1-w)`. `panelFrosted=mix(paper,bg,.58)`, `panelLit=mix(paper,cream,.84)`, `seamHairline=mix(inkStrong,bg,.14)`, `rivetBase=mix(inkStrong,surface3,.34)`, `rivetShine=mix(paper,bg,.9)`, `reliefBottomMid=mix(inkStrong,surface2,.15)`, `reliefSideDark=mix(inkStrong,surface3,.26)`. 값의 원본은 `mobile/src/theme/tokens.ts`의 `DERIVE`와 `index.ts`의 `mix`다(통합본 표와 1~2 차이가 나면 코드 산식이 맞다). 조명·그림자(`seamHighlight`·`shadowAmbient`·`shadowCast`·`shadowDeep`)는 룩과 무관한 고정값이다.
- **색 배정 85:10:5**: 화면의 85%는 무광 배경·블록 윗면, 10%는 구조(`inkStrong`·줄눈·두께면), 5%는 블록 왼쪽 스파인(`fill1~3`, 휴관 `pinClosed`). `inkStrong`으로 꽉 채우는 면은 중앙 + 기점과 하단 주 행동 버튼 1개뿐이다. 스파인은 휴관 우선, 가장 가까운 영업 중 도서관 `fill1`, 나머지 `fill2`·`fill3` 교대.
  - (제안, 채택 전) 이 원칙을 화면 테두리까지 넓히는 안과, `inkStrong` 채움 문장을 하나로 합치는 안이 아래 "제안 > 하라 켄야 레퍼런스"에 있다. 채택 전까지는 이 줄을 그대로 지킨다.

### 보류
- 포인트(링크·선택 상태)에 쓸 색은 정하지 않았다. 링크용 파랑은 구식 느낌이라 쓰지 않기로 했다.

- **정보 카드(책 상세 소장 카드) 곡률은 9**(`radii.infoCard`, modern 6, 2026-11-18 S4).
- **컨트롤(스탬프 버튼, 실시간 확인 "열기 ↗")은 완전한 필**(`border-radius: 9999px`)이다.
- **뒤로가기는 알약 없이 굵은 "‹" 하나**(선 굵기 3.6)에 은은한 그림자를 준다. "동네" 글자는 쓰지 않는다.
- **목록·카드 안의 행동은 텍스트 링크**다. 모임 카드는 검정 알약 대신 굵은 "들어가기 →"를 쓴다.
- **검정(진한색) 채움 강조는 화면에 하나**, 방문 스탬프 버튼만이다. (같은 내용을 다르게 적은 문장이 85:10:5와 S4 주 행동 버튼 행에 있다. 통합안은 "제안 > 하라 켄야 레퍼런스 > H3"에 있고, 채택 전까지는 이 줄을 그대로 지킨다.)
- **태그(게시물·방명록·방문 기록)는 배경 없이 점 + 글자**로 흐릿하게(투명도 70%) 쓴다. **모임 태그만 기존 반투명 알약**을 유지한다.

## 화면 (확정)
- 기준 화면 390×844, 상태 막대 44, 하단 바 72. 하단 바는 홈·독서 기록·글쓰기·대출·반납·내 정보(내 발자취 위치는 Q-44).
- 피드: 2열 메이슨리, 열 간격 10, 좌우 12.
- **게시물 카드는 제목·본문 없이 이미지만** 둔다(핀터레스트 느낌). 글자는 이미지 안에 들어간다(15px, 굵게, 이미지 색에 맞춰 자동 대비). 카드 높이는 제각각이다. M1은 게시물 카드만, 방명록·모임·방문 기록 카드는 M2.
- 피드와 책장(M2) 사이: 얇은 블러 띠 72px, 블러 5겹(1·1.5·2.5·3.5·4.5px)이 아래로 갈수록 강해지고 선반색으로 녹는다. 블러가 안 되는 기기는 그라데이션 페이드만.
- 책장(M2): 높이 224, 한 페이지 책 3권(표지 104×150), 좌우로 넘김.
- 서체: Noto Sans KR(400·500·700). 300(Light) 추가 여부는 "제안 > 글자·여백" T1에서 정한다. 시안 가정이며 앱 번들 때 라이선스·로딩 방식을 확인하고 확정한다.

## 문구 (확정)
- 대출 가능은 항상 데이터 기준일과 함께: "어제 기준 · 대출 가능", "어제 기준 · 대출 중". "지금 바로 대출 가능" 같은 단정 금지(02 LIB-03).
- 못 찾았을 때는 "찾지 못했어요". 응답이 없으면 "알 수 없음 + 다시 시도".
- "실시간 확인"은 외부 도서관 사이트로 이동함을 표시한다(02 LIB-06).
- "읽힌 책·인기 도서"는 대출 가능 표시가 아니다(M2 책장).

## 취향 프로필에서 가져온 것

첨부한 취향 프로필(현재 결정 9 : 취향 1로 섞음)에서 쓴 요소와 쓰지 않은 요소다.

**가져온 것**
- 순백 바탕을 쓰지 않는다 → 카드색을 `bg` 쪽으로 40% 눌렀다.
- 글자 검정 후보 #1D1D1F → 본문 글자색으로 채택(기존 #26262A).
- 컨트롤은 완전한 필(9999px) → 스탬프 버튼·"열기 ↗".
- 필은 드물게, 목록 안 행동은 텍스트 링크(굵은 글자 + 화살표) → 모임 카드 "들어가기 →".
- 검정 채움 강조는 화면에 하나 → 방문 스탬프 버튼만.
- 강조는 색이 아니라 굵기·명도 → 태그를 배경 없이 투명도로, 게시물 글자는 굵기로.
- 라벨은 "누를 수 없는 것이니 필이 아니라 회색 텍스트" → 점 + 글자 태그에 일부 반영(모임 태그는 누를 수 있는 카드의 일부라 필 유지).

**쓰지 않은 것**
- 파랑 메인·링크 파랑(#1F3FC3 등) → 사용자가 구식 느낌이라 제외. 룩별 대표색이 확정이라 충돌.
- 사진·카드 직각(`border-radius: 0`) → 아치 곡률 카드가 확정이라 충돌.
- 사진이 화면의 50~70%, 글은 한 칼럼 → 2열 메이슨리가 확정이라 충돌.
- 웜 뉴트럴을 붉은기(R > G > B)로 → 웜 온도를 낮춰(warm -20%, toffee -30%) 중성 쪽에 가깝게 했다.
- 버튼 글자 크기 35% 규칙, 아이콘 60~70% 규칙 → 시안에 해당 큰 버튼이 없어 아직 적용하지 않았다.
