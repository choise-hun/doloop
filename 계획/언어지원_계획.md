### 2. IP 및 환경 값 기반 자동 언어 설정 구현 가능 여부 및 동작 방식

외부 유료 GeoIP API나 추가 라이브러리를 전혀 쓰지 않고(지연 0ms, 개인정보 외부 전송 0건), **Cloud Run / CDN 인프라 헤더와 브라우저 내장 환경 값(`Intl` 타임존·`navigator.languages`)을 결합한 4단계 폴백 구조**로 구현할 수 있습니다.

| 우선순위 | 감지 원천 | 세부 환경 값 및 동작 방식 | 적용 환경 |
| --- | --- | --- | --- |
| **1순위** | **사용자 수동 고정** | 브라우저 `localStorage`의 `ulp:lang` (`'ko'` | `'en'` | `'ja'`) 및 로그인 계정의 `profiles.locale` 값 | 모든 환경 (수동 선택 시 최우선 유지) |
| **2순위** | **서버 IP 위치 헤더 (`ip_country`)** | `GET /api/v1/locale` 호출 시 Ktor 서버(`LocaleResolver`)가 Google Cloud Run / GFE / CDN이 주입하는 공인 IP 국가 헤더(`X-Cloud-Geo-Location`, `X-AppEngine-Country`, `CF-IPCountry`, `CloudFront-Viewer-Country`)를 읽어 `KR` → `ko`, `JP` → `ja`, 그 외 국가(`US`, `GB` 등) → `en`으로 매핑하고 `ulp:lang-auto`에 24시간 캐시 | Cloud Run 배포 환경 |
| **3순위** | **HTTP `Accept-Language` 및 브라우저 언어** | IP 위치 헤더가 없는 환경(로컬 기동 등)에서 요청 헤더의 `Accept-Language`(q 가중치 내림차순) 및 브라우저 `navigator.languages` 배열을 파싱해 `ko`·`en`·`ja` 중 첫 매칭 언어 선택 | 로컬 Ktor 서버 및 일반 브라우저 |
| **4순위** | **클라이언트 IANA 타임존 (`Intl`)** | GitHub Pages 정적 호스팅(`apiBaseUrl` 미설정)이거나 브라우저 언어가 제3언어(`zh`, `es` 등)일 때 `Intl.DateTimeFormat().resolvedOptions().timeZone`을 확인해 `Asia/Seoul` → `ko`, `Asia/Tokyo` → `ja`, 그 외 → `en`으로 즉시 추론 | GitHub Pages 단독 실행 및 오프라인 환경 |

### 3. 기존 프로젝트 아키텍처·보안 규칙과의 핵심 정합 포인트

* **X1 XSS 정적 검사([`test/security.test.js`](https://drive.google.com/file/d/18Z_eayk0JXQVFamHMcTCgb3y-PSnfOCK/view?usp=drivesdk)) 100% 호환:**
* `(a)·(b)` **CSP & 폰트:** 일본어 가독성을 위해 Google Fonts URL에 `Noto+Sans+JP`를 추가하되, 이미 `SRI_EXEMPT_STYLE`(`[https://fonts.googleapis.com/css2](https://fonts.googleapis.com/css2)?`)에 허용되어 있어 CSP 원문을 바꿀 필요가 없습니다.
* `(c)` **DOM 치환:** `public/i18n.js`는 `innerHTML`을 일절 사용하지 않고 `textContent`와 `setAttribute('placeholder' | 'aria-label' | 'title')`만 사용하며, JS에서 HTML 문자열을 조립하는 곳은 기존처럼 `esc(ULI18n.t(...))`로 감쌉니다.
* `(g)` **스토리지 키 규칙:** 신규 키를 `ulp:lang`(수동 설정)과 `ulp:lang-auto`(24시간 감지 캐시)로 지정해 `STORAGE_PREFIXES = ['ulp:', 'sb-']` 검사를 그대로 통과합니다.


* **DB 호환성 유지 ([`docs/04-db-design.md`](https://drive.google.com/file/d/1lnsAs1O_JBqi5Qbw-9sLXbKB3GzHYGeL/view?usp=drivesdk)):**
* DB `songs.status` 컬럼에는 기존과 동일하게 코드값(`practicing` | `paused` | `done`)만 저장하고, `SongDto.status` 표시 라벨만 요청 로케일에 맞춰 반환합니다(`연습 중` / `Practicing` / `練習中`).
* 화성 기호(`Cmaj7`, `G7(b9)`, `R`, `b3`, `#11`)는 번역하지 않고 고정하여 코드 연습실 계산 엔진([`ChordTheory.kt`](https://drive.google.com/file/d/1ZLcaGDn0s_RP_VEYyrrWXrM2uEEpYrms/view?usp=drivesdk), [`theory.js`](https://drive.google.com/file/d/1ncSHFJGoM87UZVN05pepgZkfzZh3dDmI/view?usp=drivesdk))이 깨지지 않게 설계했습니다.
* 노션 연동은 **2026-11-05 중단·동결**(`앱_명세.md` §5): 노션 관련 번역·호환 작업은 하지 않는다. 동결된 백엔드(`NotionPushWorker`)의 노션 속성명은 건드리지 않는다.
