## 2. 시그니처·동작

### 2.1 `public/i18n.js` — `window.ULI18n`

파일 첫 줄 주석 `// 다국어(ko·en·ja) 사전, 위치·환경 기반 자동 언어 설정 및 DOM 번역`, 다음 줄 `'use strict';`, `window.ULI18n = (function () { … return { … }; })();`.

| 함수 | 인자 | 동작 | 반환 |
| --- | --- | --- | --- |
| `getLang()` | — | 현재 활성 언어 코드 반환 (`'ko'` \| `'en'` \| `'ja'`) | `string` |
| `getMode()` | — | `'auto'`(`ulp:lang` 없음 또는 `'auto'`) \| `'manual'`(`ulp:lang`이 `'ko'`/`'en'`/`'ja'`) | `string` |
| `t(key, vars)` | `key: string`, `vars?: object` | 현재 언어 사전에서 `key` 조회 후 `{name}` 플레이스홀더를 `vars[name]`으로 치환. 현재 언어에 없으면 `ko` 폴백, 그래도 없으면 `key` 그대로 반환 | `string` |
| `setLang(langOrAuto, opts)` | `'auto'` \| `'ko'` \| `'en'` \| `'ja'`, `opts?: { syncServer?: boolean }` | 수동 언어 변경. `'auto'`면 `localStorage.removeItem('ulp:lang')` 후 환경 감지값 적용, 아니면 `localStorage.setItem('ulp:lang', lang)` 저장 → `applyDom()` → 리스너 알림 → 로그인 상태고 `opts.syncServer !== false`이면 `ULAuth.apiFetch('/api/v1/me', { method: 'PATCH', body: JSON.stringify({ locale: 현재언어 }) })` 호출 | `Promise<string>` |
| `applyDom(root)` | `root?: ParentNode` (기본 `document`) | `document.documentElement.lang = currentLang` 설정 후 `[data-i18n]`(`textContent`), `[data-i18n-placeholder]`(`placeholder`), `[data-i18n-aria]`(`aria-label`), `[data-i18n-title]`(`title`) 일괄 갱신 | `void` |
| `detectAutoLang()` | — | 2.2절 환경 추론 알고리즘 실행 | `Promise<{ locale: string, source: string, country: string \| null }>` |
| `syncWithProfile(me)` | `me: object \| null` | `getMode() === 'auto'`이고 `me && me.locale`이 지원 언어면 현재 언어를 `me.locale`로 맞추고 `applyDom()` 실행. 반대로 `getMode() === 'manual'`이고 `me && me.locale !== currentLang`이면 서버 프로필을 수동 언어로 1회 동기화 | `void` |
| `onChange(fn)` | `(lang: string) => void` | 언어 변경 시 콜백 등록 (해제 함수 반환) | `() => void` |
| `DICT` | — | `{ ko: {...}, en: {...}, ja: {...} }` (테스트에서 키 완전성 검증용 읽기 전용 노출) | `object` |

### 2.2 위치·환경 값 기반 자동 언어 결정 알고리즘 (`detectAutoLang`)

사용자가 수동으로 언어를 고정(`ulp:lang` = `'ko' | 'en' | 'ja'`)하지 않은 `'auto'` 상태일 때 다음 순서로 결정한다:

1. **세션 캐시 확인 (`ulp:lang-auto`):**
   - 매 페이지 이동마다 `/api/v1/locale`을 중복 호출하지 않도록(주니어 체크리스트 "같은 API를 이벤트마다 중복 호출하지 않는다"), `localStorage.getItem('ulp:lang-auto')`에 `{ locale, country, source, ts }`가 있고 `Date.now() - ts < 86400000`(24시간 이내)이면 캐시된 `locale`을 즉시 사용한다.
2. **클라이언트 즉시 추론 (0ms 초벌 적용 — 화면 깜빡임 방지):**
   - **2-A. 브라우저 언어 목록 (`navigator.languages` / `navigator.language`):** 순서대로 확인해 `'ko'`·`'en'`·`'ja'` 중 매칭되는 첫 언어가 있으면 초벌 언어로 선택한다.
   - **2-B. IANA 타임존 위치 추론 (`Intl.DateTimeFormat().resolvedOptions().timeZone`):** 브라우저 언어가 지원 언어 외(예: `zh`, `es`, `de`)일 때:
     - `'Asia/Seoul'` → `'ko'`
     - `'Asia/Tokyo'` → `'ja'`
     - 그 외 타임존 → `'en'`
3. **서버 IP Geo 헤더 조회 (`GET /api/v1/locale`, 타임아웃 1.5초):**
   - 캐시(`ulp:lang-auto`)가 없거나 만료되었을 때 1회 비동기 호출한다.
   - 응답의 `source === 'ip_country'`(Cloud Run / CDN이 공인 IP로 판별한 국가 코드)이면:
     - 브라우저 언어가 기본값으로 모호하거나 IP 국가(`KR`→`ko`, `JP`→`ja`, 기타→`en`)가 명확할 때 반영하고 `ulp:lang-auto`에 저장한다.
     - **우선순위 규칙:** 브라우저 OS 언어가 명시적으로 `ko`·`en`·`ja` 중 하나로 설정되어 있는 경우(예: 일본 여행 중인 한국인의 브라우저 `ko-KR` + IP `JP`), 사용자의 기기 언어(`navigator.language`)와 IP 위치(`ip_country`) 중 어느 것을 우선할지:
       - 기본 동작: **`ip_country`를 1순위로 적용**하되(요구사항 2번: IP 등의 위치 환경값으로 자동 언어 설정), 타임존(`Asia/Seoul`·`Asia/Tokyo`) 및 `navigator.languages`를 폴백(GitHub Pages 정적 호스팅 등 서버 헤더가 없을 때)으로 사용한다.
   - 네트워크 실패(오프라인 또는 GitHub Pages에서 `apiBaseUrl` 미설정) 시 에러를 삼키지 않고 내부 상태를 `{ source: 'client_env' }`로 확정한 뒤 `ulp:lang-auto`에 기록해 재호출을 막는다.

### 2.3 XSS 보안 규칙 준수 (`test/security.test.js` 호환)

- **절대 금지:** `i18n.js`에서 `innerHTML`, `outerHTML`, `insertAdjacentHTML`을 사용하지 않는다. 모든 `[data-i18n]` 치환은 오직 `el.textContent = t(key)`와 `el.setAttribute('placeholder' | 'aria-label' | 'title', t(key))`만 사용한다.
- 동적 문자열을 HTML 조각으로 이어 붙이는 기존 파일(`home.js`, `notes.js`, `app.js`)에서는 `esc(ULI18n.t(...))`로 감싸서 `security.test.js`의 `(c)` 규칙을 통과시킨다.
- `localStorage` 키는 `'ulp:lang'`(수동 설정: `'ko' | 'en' | 'ja'`)과 `'ulp:lang-auto'`(자동 감지 캐시 JSON) 두 개만 사용하여 `(g)` 규칙(`ulp:` 접두어)을 통과시킨다.

## 5. 금지 사항

- `i18n.js`에서 `innerHTML`을 쓰지 않는다(`textContent`와 속성 설정만 사용).
- 코드 심볼(`Cmaj7`, `G7(b9)`, `m7b5`), 음이름(`C`, `Db`, `F#`), 도수 기호(`R`, `b3`, `#11`, `b13`)는 국제 표준 음악 기호이므로 번역하지 않는다.
- `notes.js`에서 서버(또는 GitHub Actions)로 보내는 태그 값(`'화성'`, `'사운드 디자인'` 등 DB/스키마 enum)은 한국어 원문을 유지하고 화면 버튼의 표시 텍스트만 번역한다.
- 로그아웃이나 계정 전환 시 사용자의 기기 언어 설정(`ulp:lang`, `ulp:lang-auto`)은 기기 환경 설정이므로 지우지 않는다(단, 다른 계정으로 로그인했을 때 `getMode() === 'auto'`이면 새 계정의 `me.locale`을 따른다).
