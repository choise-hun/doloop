### 2.1 `frontend/src/lib/i18n.ts` — `i18n` & `useI18n()`

```ts
export type LocaleCode = 'ko' | 'en' | 'ja';
export type LocaleMode = 'auto' | 'manual';

export interface DetectedLocaleInfo {
  locale: LocaleCode;
  source: 'header' | 'ip_country' | 'accept_language' | 'client_env' | 'default' | string;
  country: string | null;
}

export interface I18nState {
  lang: LocaleCode;
  mode: LocaleMode;
  t: (key: string, vars?: Record<string, string | number>) => string;
  setLang: (langOrAuto: 'auto' | LocaleCode, opts?: { syncServer?: boolean }) => Promise<LocaleCode>;
}
```

- 동결된 레거시 `public/*.html` 및 `public/*.js` 파일을 수정하지 않는다 (`public/styles.css`의 `--font-body` 1줄 동기화만 예외).
- React 컴포넌트에서 `dangerouslySetInnerHTML`이나 인라인 `style={{` 속성을 쓰지 않는다 (`R0-T4`).
- 코드 심볼(`Cmaj7`, `G7(b9)`, `m7b5`), 음이름(`C`, `Db`, `F#`), 도수 기호(`R`, `b3`, `#11`, `b13`)는 국제 표준 음악 기호이므로 번역하지 않는다.
- `NotesPage.tsx`에서 서버로 보내는 태그 값(`'화성'`, `'사운드 디자인'` 등 DB/스키마 enum)과 `ProgressionsPage.tsx`에서 보내는 `kind`/`pace`/`key` 코드값은 원문을 유지하고 화면 버튼의 표시 텍스트만 번역한다.
