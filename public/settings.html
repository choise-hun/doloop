구글 계정으로 로그인하면 연습 기록과 녹음을 어디서나 이어갈 수 있어요.

계정

Google 계정으로 로그인하면 노션 설정 없이도 연습 곡과 녹음을 바로 저장할 수 있어요.

새 창에서 로그인 ↗

로그인 계정:

녹음 저장 공간 (0.0MB / 200MB)

Google Drive 녹음 저장소

녹음 오디오를 개인 Google Drive의 ULeveLP 녹음 폴더에 직접 저장해요. 서비스 저장 공간(200MB)을 차지하지 않아요.

노션 실시간 연동이 켜져 있는 동안에는 Google Drive 저장소를 사용할 수 없습니다.

계정 삭제 (모든 연습 기록·녹음·연동 키 영구 삭제)

계정을 삭제하면 서비스에 저장된 모든 곡, 연습 기록, 녹음 오디오 파일, 외부 API 키가 즉시 삭제되며 복구할 수 없어요. (본인 Google Drive에 올린 파일은 드라이브에 그대로 남아요.)

개인정보처리방침

노션 템플릿 · 데이터 내보내기/가져오기

공식 템플릿을 본인 노션에 복제한 뒤, 데이터를 ZIP으로 백업하거나 노션 백업 ZIP을 서비스로 가져올 수 있어요.

공식 노션 템플릿 복제하기 ↗

데이터 내보내기

서비스에 저장된 모든 곡, 연습 기록, 학습 영상 노트와 녹음 오디오를 노션 호환 ZIP으로 다운로드해요.

노션 백업 가져오기

노션에서 내보낸 Markdown & CSV 백업 ZIP 파일(또는 ULeveLP 내보내기 ZIP)을 올려 곡과 연습 기록을 복원해요.

    외부 연동 키 관리 · BYOK

    개인 노션과 Google Gemini API 키를 등록하면 연습 기록 실시간 동기화와 학습 노트 분석을 쓸 수 있어요. 키는 서버에 안전하게 암호화(AES-256-GCM)되어 보관돼요.
